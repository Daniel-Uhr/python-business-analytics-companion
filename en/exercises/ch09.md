### Block preparation C — Atlas Manufacturing operations records

Import pandas as `pd` and create `df_atlas` with the lists below. Elements at the same position belong to the same record.

- `unit`: `['U1', 'U2', 'U3', 'U3', 'U5', 'U6', 'U7']`.

- `quantity`: `['100', '95', '120', '120', '80', '90', '-10']`.
- `cost`: `[50000, 47000, 62000, 62000, None, 45000, 43000]`.

Atlas Manufacturing is a fictional U.S. operation. Each unit should be unique; U3 is fully duplicated. Quantity is supplied as text and must represent a nonnegative number. Cost is in U.S. dollars, with no period specified; discount is a proportion, and a missing discount means zero. Missing cost, missing department, and negative quantity have unknown correct values. No meaning or recoding rule is specified for status codes A/I. Display the table to check its construction. Work through the block in order.
