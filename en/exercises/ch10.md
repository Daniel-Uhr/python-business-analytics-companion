## Chapter Supplement

The supplement contains 19 exercises: basic grouping (01–07), management metrics (08–13), and Delta Logistics (14–19). Each block begins with a dataset preparation that you must also program. Values are author-created teaching examples; no external file is needed. Attempt the tasks before consulting the solutions chapter in the GitHub worked solutions.

Work in order within each block. Exercise 06 uses the Series from Exercises 02–04. In Block B, Exercise 10 creates the table; Exercise 11 adds result and margin; Exercise 12 checks the table; Exercise 13 uses the version with those columns. In Block C, Exercise 16 creates the center summary; Exercise 17 adds cost per unit; Exercise 19 uses that version. Exercise 18 returns to the delivery dataset and produces a separate table by center and type. Justify your choices and state units.
