## Chapter Supplement

This supplement contains 17 exercises numbered continuously across sets A, B, and C. Work in order within each set: some questions reuse values created or updated earlier. Each set starts with its own inputs. Attempt the work before consulting Solutions to Chapter 2.

## Exercises — Block C

<a id="case-orion-distribution-center"></a>

### Case: Orion Distribution Center

For the month under review, this fictional U.S. operation reports 3,200 scheduled orders, 2,985 delivered orders, operating cost of USD 186,000, a team of 36 employees, and a fulfillment rate target of 92%.

Did the operation meet its target? What can the metrics describe? Exercises 11–17 belong to the same analysis.

<a id="ex-variaveis-tipos-c1"></a>

### Exercise 11 — Organizing the Orion case

Create a text variable for the operation name and clearly named `snake_case` variables for the five values supplied in the case.

<a id="ex-variaveis-tipos-c2"></a>

### Exercise 12 — Checking three variables

Use `type()` to check at least three variables, including the operation name and two numeric variables. Explain the types you find, even if some are repeated.

<a id="ex-variaveis-tipos-c3"></a>

### Exercise 13 — Calculating fulfillment and undelivered orders

Calculate `undelivered_orders` as scheduled orders minus delivered orders. Calculate `fulfillment_rate` by dividing delivered orders by scheduled orders and multiplying by 100.

<a id="ex-variaveis-tipos-c4"></a>

### Exercise 14 — Calculating average metrics

Calculate `cost_per_delivery` by dividing operating cost by delivered orders. Calculate `deliveries_per_employee` by dividing delivered orders by the number of employees.

<a id="ex-variaveis-tipos-c5"></a>

### Exercise 15 — Comparing with the target

Create `target_met` by comparing the fulfillment rate with the target. Interpret the Boolean in Markdown. Use the calculated rate before formatting it.

<a id="ex-variaveis-tipos-c6"></a>

### Exercise 16 — Communicating the results

Produce an f-string report containing the operation name, undelivered orders, fulfillment rate, cost per delivery, deliveries per employee, and whether the target was met. Display the rate, cost per delivery, and deliveries per employee with two decimal places.

<a id="ex-variaveis-tipos-c7"></a>

### Exercise 17 — Writing the conclusion

Write two to four sentences stating the fulfillment rate, whether the target was met, how many orders were not delivered, and what cost per delivery and deliveries per employee describe. Stay within what the data support; avoid causal claims or good/bad judgments without a comparison benchmark.
