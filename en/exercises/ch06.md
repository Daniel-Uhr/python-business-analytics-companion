### Case: Boreal Manufacturing

The fictional U.S. business recorded output from four production lines across three shifts, measured in units. Each array row represents a production line, and each column represents a shift.

``` python
production = np.array([
    [480, 510, 495],
    [520, 505, 530],
    [450, 470, 460],
    [550, 545, 560]
])
```

Import NumPy and create the array in the first task. Preserve the order of lines and shifts.
