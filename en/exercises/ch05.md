### Exercise 01 — Define and Call

Create a function with no parameters named `start_report` that displays “Report started.” Then call it. Relate the definition to the operation and the call to the displayed message.

<a id="ex-funcoes-a2"></a>

### Exercise 02 — A Production Input

Create `show_production(production)` to display a message with the quantity produced. Test it with 850 units and identify the parameter and argument.

<a id="ex-funcoes-a3"></a>

### Exercise 03 — Actual Minus Planned Production

Create a function that receives actual and planned production and displays **actual minus planned production**. Test it with 850 and 800 units, in that order, and interpret the sign.

<a id="ex-funcoes-a4"></a>

### Exercise 04 — Return Total Cost

Create `calculate_total_cost(unit_cost, quantity)` to return total cost. Use a unit cost of USD 18.50 and a quantity of 240 units. Store the return value for the next exercise and display the monetary amount.

<a id="ex-funcoes-a5"></a>

### Exercise 05 — Percentage of the Budget

Reuse the cost returned in Exercise 04. Calculate and display the **percentage** it represents of a USD 5,000.00 budget. Explain your choice of denominator.

<a id="ex-funcoes-desafio-a"></a>

### Exercise 06 — One Discount Rule

An analyst repeated `price * (1 - discount / 100)` three times for different products. Create a reusable function and apply it to the price/discount pairs (200, 10), (350, 8), and (120, 5). Treat prices as U.S. dollars and discounts as percentages. Explain how the function improves this code.

### Exercise 07 — Traverse Lead Times

Create a function that receives a list of lead times and displays each one with the unit “days.” Test it with `[3, 5, 2, 7]`, preserving their order.

### Exercise 08 — Count Low Inventory Levels

### Exercise 09 — Manual Sum and Built-in Function

### Exercise 11 — Name and Docstring

Create a function that receives a list and a threshold and returns a dictionary with keys `count` and `total`: the number of values **greater than or equal to the threshold** and their sum. Test `[72, 88, 91, 65, 84]` with a threshold of 80. Explain inputs, processing, and output.

## Exercises — Block C

### Case: Orion Manufacturing

The fictional U.S. operation observes six days of production in units: `daily_production = [480, 520, 505, 450, 540, 510]`. Its daily target is `daily_target = 500`.

How can production rules and metrics be organized into reusable functions suited to this case? Design the solution without automatically copying the organization used for Atlas. Preserve the six values, their order, and the target.

<a id="ex-funcoes-c1"></a>

### Exercise 13 — Design Before Coding

Read tasks 14–18 before coding. Identify which operations deserve functions, the inputs each should receive, and the result each should return. Briefly justify your organization.

<a id="ex-funcoes-c2"></a>

### Exercise 14 — Daily Classification

Create a function that receives an observed production value and the target and returns “Below target,” “Exact target,” or “Above target.” Apply it to each day in the supplied order.

<a id="ex-funcoes-c3"></a>

### Exercise 15 — Count Days Below Target

Create a function that receives the production list and target and returns how many days fell below it. Use the case data and store the result for the report.

<a id="ex-funcoes-c4"></a>

### Exercise 16 — Cumulative Production

Create a function that receives the list, accumulates production manually, and returns the total. Compare it with `sum()` and store the return value for the report.

<a id="ex-funcoes-c5"></a>

### Exercise 17 — Interpret the Surplus Rule

Management wants to measure surplus production only on days above target: for each such day, count only the amount exceeding 500 units and accumulate those amounts. Choose the function name, signature, and return value, then implement a reusable rule.

<a id="ex-funcoes-c6"></a>

### Exercise 18 — Report and Conclusion

Use your functions to present daily classifications, the number of days below target, cumulative production, and surplus production. Write three to five sentences interpreting the results without causal claims.
