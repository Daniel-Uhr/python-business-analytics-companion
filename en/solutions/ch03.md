## Solution to Exercise 01

The list preserves the sequence of delivery times. The first element is at index 0, the second at index 1, and the last can be accessed with -1. We create the collection once and then look up three positions.

``` python
delivery_times = [4, 6, 5, 8]
print(delivery_times[0])
print(delivery_times[1])
print(delivery_times[-1])
```

``` text
4
6
8
```

The outputs are 4, 6, and 8 days. Each lookup returns an element rather than the entire list. The original order is retained; delivery times have not been sorted from smallest to largest.

<a id="sol-ch03-02"></a>

## Solution to Exercise 02

The stopping boundary is excluded from a slice. Thus, `[:2]` includes indices 0 and 1, while `[2:]` begins with the third element and continues to the end.

``` python
print(delivery_times[:2])
print(delivery_times[2:])
```

``` text
[4, 6]
[5, 8]
```

We obtain `[4, 6]` and `[5, 8]`. Both selections are lists. The original still has four elements because we have only retrieved parts of it.

## Solution to Exercise 03

The second element corresponds to index 1. Assigning 7 to that position replaces 6; it does not add an observation.

``` python
delivery_times[1] = 7
print(delivery_times)
```

``` text
[4, 7, 5, 8]
```

The list becomes `[4, 7, 5, 8]`. It still contains four elements. Using index 2 would change the third delivery time and answer a different task.

## Solution to Exercise 04

After appending 3, the list is `[4, 7, 5, 8, 3]`. Removing 8 leaves `[4, 7, 5, 3]`. The last element is now 3: `pop()` removes it and returns it for the assignment.

``` python
delivery_times.append(3)
delivery_times.remove(8)
removed_time = delivery_times.pop()
print(delivery_times)
print(removed_time)
```

``` text
[4, 7, 5]
3
```

The remaining list is `[4, 7, 5]`, and the stored value is 3. `remove(8)` received a value, not position 8. To repeat the task, recreate the earlier states; rerunning the removal alone would try to remove a value that is already gone.

## Solution to Exercise 05

Each function answers a question. `len` counts the delivery times; `sum` adds their durations; `min` and `max` identify the extremes. The mean divides the sum by the count.

``` python
print(len(delivery_times))
print(sum(delivery_times))
print(min(delivery_times))
print(max(delivery_times))
print(sum(delivery_times) / len(delivery_times))
```

``` text
3
16
4
7
5.333333333333333
```

There are three delivery times. Their durations sum to 16 days, with a minimum of 4, a maximum of 7, and a mean of approximately 5.33 days. The sum does not mean an operation took 16 elapsed days; that would depend on how deliveries overlap in time. Nor does every delivery necessarily take the mean duration.

## Solution to Exercise 06

This exercise starts a new list. The second, third, and fourth positions correspond to indices 1, 2, and 3, so the slice starts at 1 and stops before 4. The other operations summarize the entire collection, not just the selected segment.

``` python
challenge_times = [6, 4, 9, 5, 7, 4]
time_count = len(challenge_times)
shortest_time = min(challenge_times)
longest_time = max(challenge_times)
mean_time = sum(challenge_times) / len(challenge_times)
eight_days_present = 8 in challenge_times
selected_values = challenge_times[1:4]
print(time_count)
print(shortest_time)
print(longest_time)
print(mean_time)
print(eight_days_present)
print(selected_values)
```

``` text
6
4
9
5.833333333333333
False
[4, 9, 5]
```

There are six observations, with a minimum of 4, a maximum of 9, and a mean of approximately 5.83 days. A delivery time of 8 days is absent, producing `False`. The selection is `[4, 9, 5]`, in the original order. These selected values do not define a statistical measure of centrality: this exercise specifies positions, without sorting values or calculating a median.

## Solution to Exercise 07

We create a tuple with two integers. Position 0 stores the year and position 1 stores the quarter, following the convention stated in the prompt.

``` python
reporting_period = (2026, 2)
print(type(reporting_period))
print(reporting_period[0])
print(reporting_period[1])
```

``` text
<class 'tuple'>
2026
2
```

The type is `tuple`, and the values are 2026 and 2. The reference is the second quarter of 2026, not February. The tuple’s form alone does not define the unit of its second field.

## Solution to Exercise 09

The attributes have different meanings, so we associate them with descriptive keys. One possibility is a facility modernization project with a budget of 275000, Planned status, and the Operations Team as its owner.

``` python
project = {
    'name': 'Facility modernization',

    'status': 'Planned',

```


Each key identifies a piece of information, and the budget remains numeric. Other names, owners, statuses, and amounts are valid when consistent with the prompt. The USD 275,000 example is not a required input.

## Solution to Exercise 10

Retrieving the budget does not change it. Assigning to the status key replaces its earlier value; assigning to the new duration key adds information. We use In progress and ten months as illustrative choices.

``` python
print(project['budget'])
project['status'] = 'In progress'
project['duration_months'] = 10
print(project)
```

``` text
275000
{'name': 'Facility modernization', 'budget': 275000, 'status': 'In progress', 'owner': 'Operations Team', 'duration_months': 10}
```

In this answer, the displayed budget is 275000, and the new status and duration appear in the dictionary. If you chose different values in Exercise 09, keep your answer consistent with them. The criterion is to retrieve, update, and add correctly, rather than to copy the example’s choices.

## Solution to Exercise 11

The first three methods let us inspect labels, contents, and associations. The last performs a specific lookup using the owner key.

``` python
print(project.keys())
print(project.values())
print(project.items())
print(project.get('owner'))
```

``` text
dict_keys(['name', 'budget', 'status', 'owner', 'duration_months'])
dict_values(['Facility modernization', 275000, 'In progress', 'Operations Team', 10])
dict_items([('name', 'Facility modernization'), ('budget', 275000), ('status', 'In progress'), ('owner', 'Operations Team'), ('duration_months', 10)])
Operations Team
```

`keys` shows the five labels, including the added duration; `values` shows their contents; `items` keeps each key together with its value. These three results are views. Here, `get` returns only Operations Team. Your owner may differ according to Exercise 09.

## Solution to Exercise 14

``` python
total_budgets = sum(budgets)
smallest_budget = min(budgets)
largest_budget = max(budgets)
budget_range = largest_budget - smallest_budget
print(total_budgets)
print(smallest_budget)

print(budget_range)
```

``` text
895000
150000
320000
170000
```

The total is USD 895,000, the minimum USD 150,000, and the maximum USD 320,000. The range is USD 170,000. The functions return numbers, not project names. The range describes the distance between extremes; it does not establish project quality, returns, or performance.

## Solution to Exercise 16

The tuple preserves year and quarter in defined positions. The list records statuses and repetitions; the set contains only distinct values. In this answer, In progress appears twice in the list.

``` python
reference_period = (2026, 3)
project_statuses = [
    'Planned',
    'In progress',
    'Completed',
    'In progress',
]
unique_statuses = set(project_statuses)
print(reference_period)
print(unique_statuses)
print('In progress' in unique_statuses)
```

``` text
(2026, 3)
{'In progress', 'Planned', 'Completed'}
True
```

The reference is the third quarter of 2026. The set contains Planned, In progress, and Completed, and the test returns `True`. A different printed order is equally correct. The set tells us which statuses appear, but not how many projects have each status or which status belongs to each project.

The project list is preserved, and the first budget is USD 320,000. The stored lists are the same existing lists, not independent copies. The dictionary does not verify their alignment; position 0 still corresponds to the first project because we kept the order.
