## Solution to Exercise 01

First, we make the library available under the alias `pd`. The `pd.Series` constructor receives the list and associates an index with its four values. The `index` attribute lets us inspect those labels separately, while `type` identifies the resulting structure.

``` python
import pandas as pd
quantities = pd.Series([32, 28, 35, 30])
print(quantities)
print('Index:', quantities.index)
print('Type:', type(quantities))
```

``` text
0    32
1    28
2    35
3    30
dtype: int64
Index: RangeIndex(start=0, stop=4, step=1)
Type: <class 'pandas.Series'>
```

The Series contains four quantities and automatic labels 0 through 3. Those labels are not additional quantities. Since the prompt specifies no physical unit, we should not invent products, people, or days to interpret the values.


The table has four teams and three variables. Team A has 6 projects and a budget of USD 120,000. Budget is monetary, while projects is a count. The automatic index does not replace the team identifier column.

## Solution to Exercise 06

In the first access, `0:2` delimits labels and the list selects column names. In the second, both slices delimit positions. Similar notation does not change each indexer’s rules.

``` python
print(df_teams.loc[0:2, ['team', 'projects']])
print(df_teams.iloc[0:2, 0:2])
```

``` text
  team  projects
0    A         6
1    B         4
2    C         7
  team  projects
0    A         6
1    B         4
```

`loc` includes the final label 2 and returns A, B, and C: three rows. `iloc` excludes the final position 2 and returns A and B: two rows. Both selections contain the two requested variables, but use different criteria.

## Solution to Exercise 08

We build the five-product table and compare its entire revenue column with 130. The `>=` operator includes the threshold. Storing the comparison under a name lets us inspect its result before using it as a filter.

``` python
import pandas as pd
df_products = pd.DataFrame(
    {
        'product': ['P1', 'P2', 'P3', 'P4', 'P5'],
        'revenue': [90, 135, 160, 120, 185],
        'costs': [62, 88, 105, 79, 121]
    }
)
revenue_condition = df_products['revenue'] >= 130
print(revenue_condition)
```

``` text
0    False
1     True
2     True
3    False
4     True
Name: revenue, dtype: bool
```

The sequence is False, True, True, False, True. P2, P3, and P5 meet the threshold of at least USD 130,000. The condition is a Boolean Series, not an already filtered table.


Total revenue is USD 690,000 and mean revenue per product is USD 138,000. The minimum is USD 90,000 and the maximum is USD 185,000. Currency units accompany the sum, mean, and extremes; the mean is not a product count.

## Solution to Exercise 13

Profit margin is profit divided by revenue, multiplied by 100. Creating it first ensures the new subset contains that column. We then evaluate the threshold, select rows, and apply `mean` to the subset’s margins. The `.2f` format controls only the decimal places shown in the report.

``` python
df_products['margin_pct'] = (
    df_products['profit'] / df_products['revenue'] * 100
)
challenge_mask = df_products['revenue'] >= 130
subset = df_products[challenge_mask]
mean_margin = subset['margin_pct'].mean()
print(subset[['product', 'revenue', 'margin_pct']])
print(f'Mean of individual margins: {mean_margin:.2f}%')
```

``` text
  product  revenue  margin_pct
1      P2      135   34.814815
2      P3      160   34.375000
4      P5      185   34.594595
Mean of individual margins: 34.59%
```

P2, P3, and P5 form the subset; their mean margin is approximately 34.59%. Each product receives equal weight in this mean. The metric is not the ratio of total profit to total revenue. Reusing a subset created before the margin would omit the required column.

## Solution to Exercise 19

We sum orders and deliveries in the full dataset and reuse the `undelivered` column. For the overall rate, we divide total deliveries by total orders; each order enters the denominator. For mean cost per center, we apply `mean` to cost. Formatting the final two lines organizes presentation without changing calculations.

``` python
total_orders = df_meridian['orders'].sum()
total_deliveries = df_meridian['delivered'].sum()
total_undelivered = df_meridian['undelivered'].sum()
overall_rate = total_deliveries / total_orders * 100
mean_cost = df_meridian['cost'].mean()
print('Meridian Report')
print('Total orders:', total_orders)
print('Total deliveries:', total_deliveries)
print('Undelivered:', total_undelivered)
print(f'Overall rate: {overall_rate:.2f}%')
print(f'Observed mean cost: USD {mean_cost:,.2f}')
```

``` text
Meridian Report
Total orders: 6080
Total deliveries: 5740
Undelivered: 340
Overall rate: 94.41%
Observed mean cost: USD 82,300.00
```

The report contains 6,080 orders, 5,740 deliveries, and 340 undelivered orders. The overall rate is approximately 94.41%, calculated from totals rather than the simple mean of five rates. Mean cost per center is USD 82,300; it is not cost per order. A, B, D, and E were below 95%, but the data identify no causes, deadlines, or monthly period. In the output, `:,.2f` uses a comma thousands separator and a decimal point.
