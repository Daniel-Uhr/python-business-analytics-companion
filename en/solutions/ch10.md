## Solution to Exercise 01

Before choosing a method, identify the object described by each row. The dataset contains individual sales. Grouping by store will bring each establishment’s sales together, leaving one row per store in the summary. The code records this interpretation in two messages; `print()` communicates the answer but does not perform an aggregation.

``` python
print('Original: one row represents one sale.')
print('Grouped by store: one row represents one store.')
```

``` text
Original: one row represents one sale.
Grouped by store: one row represents one store.
```

Moving from sale to store changes the presentation level. The original dataset still contains seven sales, even if its summary has three rows.

<a id="sol-ch10-02"></a>

## Solution to Exercise 02

“How much was sold?” calls for accumulating revenue. `groupby("store")` gathers each store’s rows, `["revenue"]` selects the measure, and `sum()` adds its values. We save the Series as `total_revenue` for the comparison in Exercise 06.

``` python
total_revenue = df_stores.groupby('store')['revenue'].sum()
print(total_revenue)
```

``` text
store
Alpha    1800
Beta     2000
Gamma    1200
Name: revenue, dtype: int64
```

Alpha accumulates \$1,800; Beta, \$2,000; Gamma, \$1,200. The unit is dollars. Beta has the highest observed total, which does not yet tell us the number of sales or their average value.

## Solution to Exercise 03

We keep the same groups and column but change the final operation to `mean()`. The method changes because the question changes: we want the average value of a sale, not accumulated revenue. The Series will be used again in Exercise 06.

``` python
mean_revenue = df_stores.groupby('store')['revenue'].mean()
print(mean_revenue)
```

``` text
store
Alpha     600.0
Beta     1000.0
Gamma     600.0
Name: revenue, dtype: float64
```

Beta averages \$1,000 per sale; Alpha and Gamma average \$600 per sale. Equal means for Alpha and Gamma do not imply equal totals, because their numbers of sales may differ.

## Solution to Exercise 04

Each row is a sale, so we want each group’s size. `size()` counts its rows without depending on whether a revenue column is filled in. Unlike `count()` on a column, it does not count only available values in that column. We save the answer for Exercise 06.

``` python
number_of_sales = df_stores.groupby('store').size()
print(number_of_sales)
```

``` text
store
Alpha    3
Beta     2
Gamma    2
dtype: int64
```

Alpha has three sales; Beta and Gamma have two each. The counts add up to the dataset’s seven rows. This describes transaction scale, not monetary value.

## Solution to Exercise 08

After grouping by `operating_unit` and selecting `revenue`, pass a list of operations to `agg()`. Each string specifies a calculation on the same group of revenues; the result has one row per operating unit and four columns.

``` python
measures = (
```

``` text
operating_unit
```

## Solution to Exercise 09

In named aggregation, each argument on the left creates an output name and the tuple on the right pairs a column with an operation. Total and mean revenue use `revenue`; the number of orders uses `count` on `order_id`. This identifier is complete in the dataset, where each row is one order.

``` python
revenue_metrics = df_orders.groupby('operating_unit').agg(
    total_revenue=('revenue', 'sum'),
    mean_revenue=('revenue', 'mean'),
    number_of_orders=('order_id', 'count'),
)
print(revenue_metrics)
```

``` text
                total_revenue  mean_revenue  number_of_orders
operating_unit
A                        3600        1200.0                 3
B                        4800        1600.0                 3
C                        2300        1150.0                 2
```

Totals and means remain the same as in 08. Counts are 3/3/2 orders. Names communicate the measures, but the count would not automatically equal the row count if IDs were missing; it is not a count of distinct IDs either.

## Solution to Exercise 11

Start with `table` from 10. Subtract total cost from total revenue while preserving alignment by operating unit. Then divide that result by total revenue on the same row and multiply by 100. Denominators are positive in this dataset. `round(2)` controls only the display sent to `print()`.

``` python
table['total_result'] = table['total_revenue'] - table['total_cost']
table['aggregate_margin_pct'] = (
```
