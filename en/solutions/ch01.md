# Worked Solutions — Chapter 1 — Python, Jupyter, and Computational Thinking

Attempt the exercises before consulting the solutions. Open-ended questions allow other justified answers.

This chapter provides worked solutions to the 23 exercises in the Chapter 1 supplement. For open questions, the answer shown is one possibility: the criteria are to preserve the meaning, requested organization, and interpretation of the data.

## Solution to Exercise 01

The heading identifies the document for its reader. Write the markup in a Markdown cell and render it; the space after `#` separates the marker from the text. Do not use a Code cell to produce this heading.

``` markdown
# My first Python analysis
```

The result is a main heading, not a calculation output.

<a id="sol-ch01-02"></a>

## Solution to Exercise 02

A useful question states what we want to compare or understand. The example below identifies an object, an implied sales measure, and a period. Other clear questions that can be addressed with data are also valid.

Which products sold the most last month?

In an actual analysis, we would also clarify whether “most” means quantity, revenue, or another measure.

<a id="sol-ch01-03"></a>

## Solution to Exercise 03

Each list item presents one question. The marker organizes text rather than performing an operation. This is one possible answer; alternative questions can meet the same objective.

``` markdown
- Which branch generates the most revenue?
- Which costs have increased?
- Which product sold the most?
```

The list contains three items. The period and measure should be defined when each question becomes a concrete analysis.

## Solution to Exercise 04

The `+` sign requests addition of the two values. Because this is the cell’s final expression, the interactive environment displays its result.

``` python
150 + 75
```

``` text
225
```

The output `225` is the sum. Calling `print()` was not necessary here.

<a id="sol-ch01-05"></a>

## Solution to Exercise 05

In the student notebook, this cell initially has type Code. In that context, a line beginning with `#` is a comment and does not produce a heading. Select Markdown in the cell-type control and render the cell.

``` markdown
## Cell converted to Markdown
```

After conversion, `##` creates a subheading. The text is unchanged, but the cell type determines how the environment interprets it.

<a id="sol-ch01-06"></a>

## Solution to Exercise 06

The choice follows the purpose. Content that communicates and organizes the analysis belongs in the narrative; instructions to be executed belong in code.

- Heading: Markdown.
- Calculation: Code.
- Interpretation: Markdown.
- Python command: Code.

A calculation can be discussed in Markdown, but its execution takes place in a Code cell.

## Solution to Exercise 07

This task combines organization and execution. The heading identifies the analysis; a separate cell performs the subtraction.

``` markdown
# Cost analysis
```

The calculated difference is `28000`. The heading does not replace the expression, and the expression does not replace the document’s identification.

## Solution to Exercise 08

The question specifies the comparison order: planned minus actual. The first number in the expression is therefore 210000.

``` python
210000 - 148000
```

``` text
62000
```

The difference is USD 62,000: actual sales were USD 62,000 below plan. A positive result in this subtraction order does not mean performance exceeded the target.

## Solution to Exercise 09

We pass the quoted text as the function’s argument. Quotation marks delimit the text in code and do not appear in the printed message.

``` python
print("Monthly analysis")
```

``` text
Monthly analysis
```

The output was explicitly requested by `print()`.

<a id="sol-ch01-10"></a>

## Solution to Exercise 10

The expression inside the parentheses is evaluated before it is displayed. We do not quote it because we want to calculate the difference rather than print the expression as text.

``` python
print(210000 - 148000)
```

``` text
62000
```

The output `62000` comes from an explicit print call.

## Solution to Exercise 11

The comment should clarify the calculation’s order and purpose. Different wording is acceptable if it remains consistent with planned minus actual.

``` python
# Difference between planned and actual sales
210000 - 148000
```

``` text
62000
```

The comment does not change the result `62000`; it helps preserve its meaning.

<a id="sol-ch01-12"></a>

## Solution to Exercise 12

While the line is commented, it is not executed. Once it becomes an instruction, we must close the parenthesis opened after `print`. The quotation marks already delimit the message correctly.

``` python
print("Monthly revenue")
```

``` text
Monthly revenue
```

The solution prints the message. The aim is to identify and correct the syntax, not to leave an active error in the initial notebook.

## Solution to Exercise 13

The first line calls a printing function. The second is the cell’s final expression, whose value is displayed by the interactive environment.

``` python
print("Monthly profit")
120000 - 85000
```

``` text
Monthly profit
35000
```

`Monthly profit` is printed by `print()`; `35000` is displayed as the final expression’s value. The message is only a label: it does not establish that the difference is a complete accounting measure of profit.

## Solution to Exercise 14

The help shows that we can supply the number and the decimal-place count. We use three as the second argument. Help presentation may vary across versions, but it should let us identify this purpose.

``` python
help(round)
```

Python displays the following built-in help:

``` text
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None.  Otherwise
    the return value has the same type as the number.  ndigits may be negative.
```

``` python
round(17.43891, 3)
```

``` text
17.439
```

The rounded result is `17.439`. It approximates the initial value to the requested precision.

<a id="sol-ch01-15"></a>

## Solution to Exercise 15

The expression calculates a difference, compares it with 250000, and converts the proportion to a percentage. We pass the expression directly to `round`, with two as its second argument.

``` python
round((250000 - 172000) / 250000 * 100, 2)
```

``` text
31.2
```

The output is `31.2`, corresponding to the percentage notation 31.20%. Numerical rounding does not force a trailing zero to be displayed.

<a id="sol-ch01-16"></a>

## Solution to Exercise 16

Before calculating, we identify the case and the values being used. This context lets another person interpret the subsequent expressions without reconstructing the question.

``` markdown
# Monthly analysis — Horizon Retail
## Data
- Revenue: USD 185,000
- Costs: USD 126,000
- Margin target: 30%
```

The values are didactic. The target is a percentage; revenue and costs are monetary amounts.

<a id="sol-ch01-17"></a>

## Solution to Exercise 17

The question determines the subtraction order: revenue minus costs. We use the numbers supplied in the case directly.

``` python
185000 - 126000
```

``` text
59000
```

The simplified difference is USD 59,000. It compares the supplied quantities and is not necessarily a complete accounting measure of profit.

<a id="sol-ch01-18"></a>

## Solution to Exercise 18

We divide the difference by revenue to obtain a proportion. We multiply by 100 because the target is expressed as a percentage; the comparison requires compatible units.

``` python
(185000 - 126000) / 185000 * 100
```

``` text
31.891891891891895
```

The output `31.891891891891895` corresponds to approximately 31.89% of revenue.

<a id="sol-ch01-19"></a>

## Solution to Exercise 19

We put the entire margin expression in the first argument of `round`, so the calculation’s result is rounded, and use two as the second argument.

``` python
round((185000 - 126000) / 185000 * 100, 2)
```

``` text
31.89
```

The rounded value is `31.89`; in English prose, we write approximately 31.89%.

<a id="sol-ch01-20"></a>

## Solution to Exercise 20

The first call prints a message; the second prints the numerical result. Each call presents its output on a line.

``` python
print("Analysis result")
print(round((185000 - 126000) / 185000 * 100, 2))
```

``` text
Analysis result
31.89
```

The output associates the message with `31.89`. The percentage interpretation still needs to be stated in the text.

<a id="sol-ch01-21"></a>

## Solution to Exercise 21

We choose the margin and record the expression’s meaning. Other comments are valid when they accurately describe the calculation they accompany.

``` python
# Simplified percentage margin
round((185000 - 126000) / 185000 * 100, 2)
```

``` text
31.89
```

The comment documents the operation without changing the output `31.89`.

<a id="sol-ch01-22"></a>

## Solution to Exercise 22

The comparison must use the same indicator and unit as the target. The calculated margin is a percentage, just like the 30% target.

The simplified margin was approximately 31.89%, exceeding the 30% target. Based on this indicator and the supplied data, the target was met.

This conclusion answers the case question; it does not by itself establish satisfactory performance across every dimension of the business.

<a id="sol-ch01-23"></a>

## Solution to Exercise 23

The conclusion should bring together the essential results and answer the requested decision question. Different wording is acceptable if values, units, and interpretation are preserved.

``` markdown
## Conclusion
Horizon Retail reported a difference of USD 59,000 between revenue and costs. Its simplified margin was approximately 31.89%, exceeding the 30% target. Based on this indicator and the supplied data, the target was met.
```

The answer contains three sentences. It does not claim that the difference is a complete accounting measure of profit or recommend an action unsupported by the case.
