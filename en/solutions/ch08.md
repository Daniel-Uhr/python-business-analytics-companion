## Block preparation A

Import pandas and construct the block dataset. Each list provides a column; values at the same position form one observation. Data and units were defined in the supplement preparation.

``` python
import pandas as pd
df_units = pd.DataFrame(
    {
        'unit': ['U1', 'U2', 'U3', 'U4', 'U5', 'U6'],
        'region': ['South', 'Southeast', 'South', 'Midwest', 'Southeast', 'North'],
        'revenue': [180, 145, 210, 168, 195, 132],
        'costs': [125, 108, 152, 121, 138, 99]
    }
)
print(df_units)
```

``` text
  unit     region  revenue  costs
0   U1      South      180    125
1   U2  Southeast      145    108
2   U3      South      210    152
3   U4    Midwest      168    121
4   U5  Southeast      195    138
5   U6      North      132     99
```

## Solution to Exercise 01

First, compare each revenue with 180. Because amounts are in thousands of dollars, the threshold means USD 180,000. The mask selects rows; the list after the comma in `.loc` chooses the two requested columns.

``` python
mask = df_units['revenue'] >= 180
result = df_units.loc[mask, ['unit', 'revenue']]
print(result)
```

``` text
  unit  revenue
0   U1      180
2   U3      210
4   U5      195
```

U1, U3, and U5 remain, with revenue of 180, 210, and 195 thousand dollars. U1 shows that equality is included. Labels 0, 2, and 4 preserve the original row identities.

## Solution to Exercise 02

The comparison `< 120` produces a Boolean Series. Here, we inspect the condition without yet using it to create a filtered table.

``` python
costs_condition = df_units['costs'] < 120
print(costs_condition)
```

``` text
0    False
1     True
2    False
3    False
4    False
5     True
Name: costs, dtype: bool
```

The values are False, True, False, False, False, and True. U2 and U6 have costs below 120 thousand dollars. `True` means the row meets this criterion, not that the unit is generally satisfactory. The boundary value 120 would be excluded.

## Solution to Exercise 03

The criteria concern the same row: sufficient revenue and costs within the limit. Building them separately lets us review each question before applying `&`. Both Series retain the index of `df_units`.

``` python
revenue_condition = df_units['revenue'] >= 170
costs_condition = df_units['costs'] <= 140
mask = revenue_condition & costs_condition
print(df_units[mask])
```

``` text
  unit     region  revenue  costs
0   U1      South      180    125
4   U5  Southeast      195    138
```

U1 and U5 meet both criteria. U3 has sufficient revenue but costs of 152, above 140; high revenue alone does not qualify it. The thresholds are in thousands of dollars.

<a id="sol-ch08-04"></a>

## Solution to Exercise 04

The first query uses `|` because either territory qualifies. The second uses `~` to reverse the South condition. The final brackets limit the display to unit and region; no values are assigned through these selections.

``` python
south = df_units['region'] == 'South'
southeast = df_units['region'] == 'Southeast'
print(df_units[south | southeast][['unit', 'region']])
print('Outside South:')
print(df_units[~south][['unit', 'region']])
```

``` text
  unit     region
0   U1      South
1   U2  Southeast
2   U3      South
4   U5  Southeast
Outside South:
  unit     region
1   U2  Southeast
3   U4    Midwest
4   U5  Southeast
5   U6      North
```

South or Southeast includes U1, U2, U3, and U5. Outside South includes U2, U4, U5, and U6. These queries differ: one lists two accepted categories, while the other excludes one category.

<a id="sol-ch08-05"></a>

## Solution to Exercise 05

`isin()` gathers the accepted labels in a list. After applying the mask, `shape[0]` reads the row count: position 0 of the dimensions tuple contains the number of observations.

``` python
regions_mask = df_units['region'].isin(['South', 'Southeast'])
result = df_units[regions_mask]
print(result[['unit', 'region']])
print('Count:', result.shape[0])
```

``` text
  unit     region
0   U1      South
1   U2  Southeast
2   U3      South
4   U5  Southeast
Count: 4
```

There are four rows, for U1, U2, U3, and U5, as in the first query of Exercise 04. The match is not based on count alone: the identifiers also confirm the intended selection.

<a id="sol-ch08-06"></a>

## Solution to Exercise 06

`between(145, 195)` includes both endpoints by default. We apply its mask in `.loc` and choose columns that let us check unit and revenue side by side.

``` python
interval_mask = df_units['revenue'].between(145, 195)
print(df_units.loc[interval_mask, ['unit', 'revenue']])
```

``` text
  unit  revenue
0   U1      180
1   U2      145
3   U4      168
4   U5      195
```

U1, U2, U4, and U5 remain. U2 is at the lower endpoint, 145, and U5 at the upper endpoint, 195. Including both agrees with the prompt. U3, at 210, lies above the interval.

<a id="sol-ch08-07"></a>

## Solution to Exercise 07

One readable solution uses `isin()` for territory membership and `between()` for the revenue interval. A copy provides a working version of the table. We combine the masks with `&` because a unit must meet both requirements.

``` python
df_challenge = df_units.copy()
region_mask = df_challenge['region'].isin(['South', 'Southeast'])
revenue_mask = df_challenge['revenue'].between(160, 205)
challenge_result = df_challenge[region_mask & revenue_mask]
print(challenge_result)
```

``` text
  unit     region  revenue  costs
0   U1      South      180    125
4   U5  Southeast      195    138
```

U1 and U5 meet the rule. U4 has revenue within the interval but belongs to Midwest; U3 belongs to South but exceeds the revenue ceiling. Equivalent explicit comparisons are also acceptable when the explanation and boundaries are correct.

## Solution to Exercise 08

Subtract spending from budget in each row. The new `balance` column receives the difference in the same monetary unit as its inputs: dollars. The table now stores this result for reuse.

``` python
df_projects['balance'] = df_projects['budget'] - df_projects['spending']
print(df_projects[['project', 'budget', 'spending', 'balance']])
```

``` text
  project  budget  spending  balance
0      P1  120000    108000    12000
1      P2   95000     97000    -2000
2      P3  150000    142000     8000
3      P4  110000    101000     9000
4      P5  135000    128000     7000
```

Balances are 12,000, −2,000, 8,000, 9,000, and 7,000 dollars. P2’s negative value indicates spending USD 2,000 above budget. A positive balance indicates unspent budget, without demonstrating that a project is complete.

## Solution to Exercise 09

Copy the current state of `df_projects` and divide only `budget` by 1,000 in the copy. The final lookup uses the original object, row label 0, and the budget column.

``` python
df_thousands = df_projects.copy()

print(df_thousands[['project', 'budget']])
```

``` text
3      P4   110.0
4      P5   135.0
Original preserved: 120000
```

The copy shows 120, 95, 150, 110, and 135 thousand dollars; the first original value remains 120,000. Spending and balance in the copy remain in dollars. Do not combine them with budget in thousands in new subtractions. Subsequent exercises return to the original table.

## Solution to Exercise 10

The `columns` argument receives a mapping from old to new names. Store the result of `rename()` in another object and convert its column index to a list to inspect the names.

``` python
df_names = (

print(list(df_names.columns))
```

``` text
['project', 'budget_usd', 'spending_usd', 'priority', 'year', 'balance']
```

Budget and spending receive unit suffixes; their values do not change. The list also includes `balance`, created in Exercise 08. This confirms that we are following the sequentially constructed table rather than silently restarting it.

## Solution to Exercise 11

Create a copy to preserve the original codes. `replace()` applies the dictionary to the priority column, and assignment stores the substituted labels in that column of the copy.

``` python
df_priorities = df_projects.copy()
print('Before:', list(df_priorities['priority']))
df_priorities['priority'] = (
    df_priorities['priority'].replace({'A': 'High', 'B': 'Medium', 'C': 'Low'})
)
print('After:', list(df_priorities['priority']))
```

``` text
Before: ['A', 'B', 'A', 'C', 'B']
After: ['High', 'Medium', 'High', 'Low', 'Medium']
```

A, B, A, C, B becomes High, Medium, High, Low, Medium. The codes become readable, but no ranking order has been created: replacing descriptions is not the same as configuring an ordered category.

Use the balance calculated in Exercise 08. `sort_values(..., ascending=False)` returns a sorted table, stored under a new name. The final lists explicitly compare original and returned row orders.

``` python
df_sorted = df_projects.sort_values('balance', ascending=False)
print(df_sorted[['project', 'balance']])
print('Original table order:')
print(list(df_projects['project']))
```

``` text
['P1', 'P2', 'P3', 'P4', 'P5']
```

The order is P1, P4, P3, P5, and P2. P1 leads with a balance of USD 12,000, meaning the largest difference between budget and spending, not necessarily better execution. The original table retains P1, P2, P3, P4, and P5.

## Solution to Exercise 13

This is one possible solution. Select the five original columns to make the starting point explicit, then copy them. Calculate balance and percentage spent, convert year to text, and recode priority. Since all budgets are positive, spending no more than budget corresponds to a percentage spent of at most 100%.

``` python
df_pipeline = (
    df_projects[['project', 'budget', 'spending', 'priority', 'year']].copy()
)
df_pipeline['balance'] = df_pipeline['budget'] - df_pipeline['spending']
df_pipeline['spent_pct'] = (
    df_pipeline['spending'] / df_pipeline['budget'] * 100
)
df_pipeline['year'] = df_pipeline['year'].astype(str)
df_pipeline['priority'] = (
    df_pipeline['priority'].replace({'A': 'High', 'B': 'Medium', 'C': 'Low'})
)
mask = df_pipeline['spent_pct'] <= 100
report = df_pipeline[mask].sort_values('spent_pct', ascending=False)
print(report)
print('Dimensions:', report.shape)
print('Columns:', list(report.columns))
print('Nonincreasing order:', report['spent_pct'].is_monotonic_decreasing)
```

``` text
  project  budget  spending priority  year  balance  spent_pct
4      P5  135000    128000   Medium  2025     7000  94.814815
2      P3  150000    142000     High  2025     8000  94.666667
3      P4  110000    101000      Low  2025     9000  91.818182
0      P1  120000    108000     High  2025    12000  90.000000
Dimensions: (4, 7)
Columns: ['project', 'budget', 'spending', 'priority', 'year', 'balance', 'spent_pct']
Nonincreasing order: True
```

The report contains P5, P3, P4, and P1 in that order and has shape (4, 7). P2 is excluded because it spent approximately 102.11% of budget. The remaining percentages are approximately 94.81%, 94.67%, 91.82%, and 90%. Shape, column names, displayed values, and the ordering property provide specific checks. The percentage measures budget use, not physical progress, completion, or project success. Interpret the year conversion in light of the pandas version’s string behavior.

## Solution to Exercise 14

The first measure compares production with that row’s target; the second divides total cost by the quantity produced. Targets and production are positive in this dataset, so the divisions are defined. Store both measures in new columns.

``` python
df_vertex['attainment_pct'] = (
    df_vertex['production'] / df_vertex['target'] * 100
)
df_vertex['unit_cost'] = df_vertex['cost'] / df_vertex['production']
print(df_vertex[['unit', 'attainment_pct', 'unit_cost']])
```

## Solution to Exercise 15

Compare `production` with `target` row by row. The cost condition uses total cost, not the per-unit measure created in the previous exercise. With `&`, both conditions must hold.

``` python
target_condition = df_vertex['production'] >= df_vertex['target']
cost_condition = df_vertex['cost'] <= 80000
criteria_result = df_vertex[target_condition & cost_condition]
print(criteria_result[['unit', 'production', 'target', 'cost']])
```

``` text
  unit  production  target   cost
0  V01         520     500  78000
3  V04         490     480  69000
6  V07         530     510  76000
```

V01, V04, and V07 meet both requirements. V03 exceeds its target but has total cost of USD 91,000 and is excluded. No single target was imposed on all units; each production value was compared with its corresponding target.

## Solution to Exercise 19

Check shape, names, and sequence. `unique()` returns distinct values in order of appearance, and `list()` makes them easy to read. We retain the shift inspection in the working table and add a direct inspection of the report to check the object actually delivered. The ordering property allows ties. Finally, reuse the target-and-cost filter from Exercise 15 and use `.iloc[0]` to access the first position of the sorted report. See also the documentation on unique values (The pandas development team n.d.).

``` python
print('Report dimensions:', vertex_report.shape)
print('Columns:', list(vertex_report.columns))
print('Shifts present:', list(vertex_working['shift'].unique()))
print('Shifts in the report:', list(vertex_report['shift'].unique()))
print('Nonincreasing order:', vertex_report['attainment_pct'].is_monotonic_decreasing)
print('Units meeting target and cost criteria:', list(criteria_result['unit']))
print('Highest observed attainment:', vertex_report.iloc[0]['unit'])
print(f"Percentage: {vertex_report.iloc[0]['attainment_pct']:.2f}%")
```

``` text
Report dimensions: (5, 6)
Columns: ['unit', 'department', 'shift', 'production', 'target', 'attainment_pct']
Shifts present: ['Day', 'Night']
Shifts in the report: ['Day', 'Night']
Nonincreasing order: True
Units meeting target and cost criteria: ['V01', 'V04', 'V07']
Highest observed attainment: V03
Percentage: 105.17%
```

Shape is (5, 6); the report contains Day and Night shifts. The order is nonincreasing. V01, V04, and V07 meet both target and cost criteria; V03 leads the attainment report at 105.17% after display rounding. `:.2f` controls the two displayed decimals without redefining the stored value. Category presence in the full table alone would not guarantee presence in the filtered report; the additional line checks that directly. These inspections do not certify overall data quality or a causal performance comparison.
