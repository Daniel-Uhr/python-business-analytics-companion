## Solution to Exercise 01

Both files are author-created teaching data. The CSV has one branch in one month per row. The Excel workbook contains two tables: `units`, with one operating unit per row, and `targets`, with one unit in one year per row. Format describes representation; observation unit describes what a record means. Both should be documented.

Revenue and revenue targets are fictional U.S. dollar amounts in ordinary currency units. CSV margin is a percentage; Excel target margin is a fraction. These files do not describe actual companies.

## Solution to Exercise 08

The local documentation identifies the U.S. Census Bureau and its TIGERweb service. The endpoint is `https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/0/query`. It is a data query address, not merely an informational web page.

The query selects REGION codes 1–4, requests STATE/STUSAB/NAME/REGION/DIVISION, omits geometry, orders by STATE, requests up to 100 records, and uses JSON. These parameters define the 50-state-plus-DC coverage; preserve them with the endpoint.

## Solution to Exercise 16

Northstar received a fictional business CSV and a prepared snapshot derived from the official Federal Reserve file. The first has branch–month observations with revenue and margin. The second has monthly observations of a national industrial production index. Both are CSV files, but their meanings and reading conventions differ.

The files do not share a substantive key for the intended combination. A common month does not make the national index a branch-specific measure.

<a id="sol-ch15-17"></a>

## Solution to Exercise 17

The branch export requires semicolons and decimal commas. The prepared Fed snapshot uses conventional comma-separated fields and decimal points. Applying one configuration indiscriminately can misread one of the files.

``` python

ip = pd.read_csv(DATA / 'fed_ip_2023_2024_snapshot.csv')
```

## Solution to Exercise 18

Numeric business fields are checked during import; explicitly converting the index reinforces its numeric contract. `.copy()` separates the working table from the intermediate selection.

Both tables have temporal columns, but not the same observation unit. Business margin remains a percentage; the index is not currency and will not be compared directly with revenue.
