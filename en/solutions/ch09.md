## Block preparation A

Import pandas and construct the block dataset. Each list provides a column; values at the same position form one observation. Data and units were defined in the supplement preparation.

``` python
import pandas as pd
df_orders = pd.DataFrame(
    {
        'order': ['P1', 'P2', 'P3', 'P4', 'P5', 'P6'],
        'revenue': [120, None, 95, 140, None, 110],
        'discount': [0.05, None, 0.0, 0.1, None, 0.03],
        'channel': ['Store', 'Online', 'Store', 'Online', None, 'Store']

print(df_orders)
```

``` text
  order  revenue  discount channel
0    P1    120.0      0.05   Store
1    P2      NaN       NaN  Online
2    P3     95.0      0.00   Store
3    P4    140.0      0.10  Online
4    P5      NaN       NaN     NaN
5    P6    110.0      0.03   Store
```

## Solution to Exercise 01

The question is where information is missing, not which value should occupy each position. Apply `isna()` to the whole DataFrame and print the mask. Its shape is retained, so each Boolean value can be matched to its row and column.

``` python
print(df_orders.isna())
```

``` text
   order  revenue  discount  channel
0  False    False     False    False
1  False     True      True    False
2  False    False     False    False
3  False    False     False    False
4  False     True      True     True
5  False    False     False    False
```

P2 and P5 have missing revenue and discount; P5 also lacks a channel. `True` locates missing information without choosing a treatment. The zero discount in P3 is a known value and is marked `False` by this check.

<a id="sol-ch09-02"></a>

## Solution to Exercise 02

Reuse the missing-value mask and sum its rows within each column. Each `True` contributes one. The result is a Series whose labels are the column names and whose values are the counts.

``` python
print(df_orders.isna().sum())
```

``` text
order       0
revenue     2
discount    2
channel     1
dtype: int64
```

Order has no missing values; revenue and discount each have two; channel has one. Adding these counts would give five missing cells, not five different orders.

<a id="sol-ch09-03"></a>

## Solution to Exercise 03

The mean of a Boolean mask divides the missing-value count by the row count. Multiply by 100 to obtain percentages. The denominator is six for every column because we are examining the complete dataset.

``` python
print(df_orders.isna().mean() * 100)
```

``` text
order        0.000000
revenue     33.333333
discount    33.333333
channel     16.666667
dtype: float64
```

Revenue and discount are each 33.33% missing; channel is 16.67% missing. These percentages describe the extent of the problem. They do not establish that filling or exclusion is appropriate or provide a universal quality threshold.

<a id="sol-ch09-04"></a>

## Solution to Exercise 04

`notna()` returns `True` where revenue is available. Use this mask inside the brackets of `df_orders`, retaining all columns of the selected rows. No assignment modifies the original dataset.

``` python
print(df_orders[df_orders['revenue'].notna()])
```

``` text
  order  revenue  discount channel
0    P1    120.0      0.05   Store
2    P3     95.0      0.00   Store
3    P4    140.0      0.10  Online
5    P6    110.0      0.03   Store
```

P1, P3, P4, and P6 have recorded revenue. Their index labels remain 0, 2, 3, and 5. The criterion checks availability without certifying every field in these orders.

<a id="sol-ch09-05"></a>

## Solution to Exercise 05

`subset` limits the exclusion decision to revenue. Store the result of `dropna()` in `report` and print the shapes of the dataset and selection. This distinguishes an analysis version from the original information.

``` python
report = df_orders.dropna(subset=['revenue'])
print('Before/after:', df_orders.shape, report.shape)
```

``` text
Before/after: (6, 4) (4, 4)
```

The dataset still has six rows and four columns; the report has four rows and four columns. P2 and P5 were excluded only from this report. Later exercises requiring the complete dataset must return to `df_orders`.

<a id="sol-ch09-06"></a>

## Solution to Exercise 06

The rule states that a missing discount means zero. Copy the complete dataset, apply `fillna(0)` only to the discount column, and assign the result back to that column. The final selection lets us check each order and its discount.

``` python
df_working = df_orders.copy()
df_working['discount'] = df_working['discount'].fillna(0)
print(df_working[['order', 'discount']])
```

``` text
  order  discount
0    P1      0.05
1    P2      0.00
2    P3      0.00
3    P4      0.10
4    P5      0.00
5    P6      0.03
```

P2 and P5 now have zero discounts; known discounts are retained. All six rows remain in the copy. Revenue and channel were not filled because no rule supplied their correct values.

## Solution to Exercise 07

There are three distinct decisions. Fill discount under the supplied rule; keep revenue and channel unknown in the complete copy; and separately create the report that requires revenue. Starting from `df_orders` avoids accidentally inheriting the exclusion from Exercise 05. The displays allow inspection of both versions and the final diagnosis of the complete copy.

``` python
df_decision = df_orders.copy()

revenue_report = df_decision.dropna(subset=['revenue'])
```

The copy retains six orders, two unknown revenues, and one unknown channel, with complete discounts. The report contains four orders. The missing channel for P5 was not discovered: that order simply does not belong to the selection requiring revenue. The recommendation must make this difference explicit.

## Solution to Exercise 08

Store the result of `duplicated()` in `m`. The first display shows the decision for each row; `df_suppliers[m]` displays the marked record; `m.sum()` counts excess occurrences. No row is removed at this stage.

``` python
m = df_suppliers.duplicated()
print(m)
print(df_suppliers[m])
print('Count:', m.sum())
```

``` text
0    False
1    False
2    False
3     True
4    False
5    False
dtype: bool
  code   category  lead_time
3   F3  EQUIPMENT         20
Count: 1
```

Only index 3, the second complete occurrence of F3, receives `True`. The count is one. The preparation rule confirms that each supplier record should be unique and that this repetition is incorrect.

<a id="sol-ch09-09"></a>

## Solution to Exercise 09

Because the diagnosis and context confirmed the error, store `drop_duplicates()` in `df_unique`. `shape` compares rows and columns together; the first number of each pair is the record count.

``` python
df_unique = df_suppliers.drop_duplicates()
print('Before/after:', df_suppliers.shape, df_unique.shape)
```

``` text
Before/after: (6, 3) (5, 3)
```

The shape changes from `(6, 3)` to `(5, 3)`. The first F3 occurrence remains; index labels are 0, 1, 2, 4, and 5. Use `df_unique` for the next category inspections without overwriting `df_suppliers`.

<a id="sol-ch09-10"></a>

## Solution to Exercise 10

Select the category column from the version without duplicates and call `unique()`. The result shows distinct values in order of appearance. Inspection comes before deciding which representations can be standardized.

``` python
print(df_unique['category'].unique())
```

``` text
<StringArray>
['Supplies', ' supplies ', 'EQUIPMENT', 'Technical Part', 'technical-part']
Length: 5, dtype: str
```

There are five spellings. `Supplies` and `' supplies '` differ in whitespace and capitalization; `Technical Part` and `technical-part` also differ in hyphenation. These differences will be treated in stages while retaining the underlying category.

<a id="sol-ch09-11"></a>

## Solution to Exercise 11

`str.strip()` acts on leading and trailing whitespace in each string. Store the resulting Series in `category_strip` without modifying the table. Inspecting unique values shows exactly what changed.

``` python
category_strip = df_unique['category'].str.strip()
print(category_strip.unique())
```

``` text
<StringArray>
['Supplies', 'supplies', 'EQUIPMENT', 'Technical Part', 'technical-part']
Length: 5, dtype: str
```

`' supplies '` became `supplies`, without the surrounding spaces. The letters remain lowercase; there was no change in meaning to another category. The capitalization difference from `Supplies` is addressed in the next exercise.

<a id="sol-ch09-12"></a>

## Solution to Exercise 12

Use the Series without surrounding spaces from Exercise 11. `str.title()` standardizes capitalization, and its result is stored in `category_title`. This dependency avoids returning to the spellings with extra spaces.

``` python
category_title = category_strip.str.title()
print(category_title.unique())
```

``` text
<StringArray>
['Supplies', 'Equipment', 'Technical Part', 'Technical-Part']
Length: 4, dtype: str
```

Four spellings remain: Supplies, Equipment, Technical Part, and Technical-Part. The first two are uniform. The internal-space versus hyphen difference remains and requires the catalog rule in the next task.

<a id="sol-ch09-13"></a>

## Solution to Exercise 13

This catalog uses `Technical-Part` as its standard. Apply `replace()` to the title-cased Series from Exercise 12, using a dictionary that maps the unhyphenated spelling to the desired label. This rule neither removes nor rearranges suppliers.

``` python
category_final = category_title.replace({'Technical Part': 'Technical-Part'})
print(category_final.unique())
```

``` text
<StringArray>
['Supplies', 'Equipment', 'Technical-Part']
Length: 3, dtype: str
```

Three underlying categories remain: Supplies, Equipment, and Technical-Part. The hyphen is an explicit convention of this fictional catalog, not a general English spelling rule. Do not impose the same standard on every vocabulary without checking its meaning.

<a id="sol-ch09-14"></a>

## Solution to Exercise 14

Start again from `df_suppliers`, remove the confirmed repetition, and copy the result. Store the categories before standardization. Remove surrounding spaces in an intermediate Series. Then assign capitalization and recoding to the copy’s column. Finally, compare the duplicate count with the original dataset and inspect categories before and after treatment.

``` python
df_clean = df_suppliers.drop_duplicates().copy()
before = df_clean['category'].unique()
category = df_clean['category'].str.strip()
df_clean['category'] = category.str.title()
df_clean['category'] = (
    df_clean['category'].replace({'Technical Part': 'Technical-Part'})
)
print('Duplicates before/after:', df_suppliers.duplicated().sum(), df_clean.duplicated().sum())
print('Categories before:', before)
print('Categories after:', df_clean['category'].unique())
```

``` text
Duplicates before/after: 1 0
Categories before: <StringArray>
['Supplies', ' supplies ', 'EQUIPMENT', 'Technical Part', 'technical-part']
Length: 5, dtype: str
Categories after: <StringArray>
['Supplies', 'Equipment', 'Technical-Part']
Length: 3, dtype: str
```

Excess repetitions fell from one to zero; the copy has five records. The five spellings found after deduplication converge to three categories. The variable `before` holds categories before text standardization, not a second copy of the entire table. The original dataset remains available.

## Solution to Exercise 15

Start with missing-value and duplicate counts, department values, and the quantity dtype. To compare quantity with zero, convert the valid integer strings into a temporary Series, `numeric_quantity`. This assignment does not replace the original column. The temporary mask selects the invalid record, displayed with quantity still stored as text.

``` python
print('Missing:')
print(df_atlas.isna().sum())
print('Duplicates:', df_atlas.duplicated().sum())
print('Departments:', df_atlas['department'].unique())
print('Quantity type:', df_atlas['quantity'].dtype)
numeric_quantity = df_atlas['quantity'].astype(int)
print('Invalid quantity:')
print(df_atlas[numeric_quantity < 0][['unit', 'quantity']])
```

``` text

status        0
```

There is one missing department, one missing cost, and two missing discounts, plus one fully repeated U3 record. Department spellings are inconsistent, and quantity is stored as text. U7 contains -10: it can be converted, but it violates the nonnegative-quantity rule.

Before transforming the table, record the decisions. The messages below separate justified actions, a possible conversion, and unresolved issues. `print()` only communicates this classification; it does not alter records or resolve unknown values.

``` python
print('Can address: duplicate U3, missing discount, and department spellings.')
```

## Solution to Exercise 18

The quantity column in the working version is now numeric. The comparison `< 0` produces the mask; the selection stores rule-violating rows in `invalid_rows`. Printing unit and quantity identifies the issue without replacing its value.

``` python
invalid_rows = atlas_clean[atlas_clean['quantity'] < 0]
```


## Solution to Exercise 19
