Daniel de Abreu Pereira Uhr — Python for Business Analytics.

Contains 16 student notebooks with exercise prompts and answer spaces. Worked solutions are in the `solutions` folder. Open notebooks in this folder and keep `data/ch15` and `data/ch16` alongside them. Use Python 3.11.5 and the dependencies recorded in `environment`; `requirements-*.lock.txt` files are installation inputs and `chNN-runtime.lock.txt` files are observed version records. Dependencies were verified on Windows; other platforms may require adapting `pywin32`. Select the appropriate kernel and run cells in order.

Use the corresponding environment for each stage:1–5 Python foundations;6 NumPy;7–13 pandas;14 visualization;15 files/APIs;16 project. Pinned dependency files for stages 1,6,7,14,15 and 16 are included. Do not install all lists consecutively into the same environment. The Jupyter/VS Code interface may be installed separately.

Live requests in 15 are optional and disabled by default; snapshots preserve reproducibility. See [data notices](DATA-NOTICES.md) and [licenses](../LICENSE-SCOPE.md).
