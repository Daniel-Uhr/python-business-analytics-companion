Contém 16 notebooks do estudante, com enunciados e espaços de resposta. As resoluções comentadas estão na pasta `solutions`. Abra os notebooks nesta pasta e preserve `data/ch15` e `data/ch16` ao lado deles. Use Python 3.11.5 e as dependências registradas na pasta `environment`; os arquivos `requirements-*.lock.txt` são entradas de instalação e `chNN-runtime.lock.txt` são registros de versões. As dependências foram verificadas no Windows; outras plataformas podem exigir adaptação de `pywin32`. Selecione o kernel apropriado e execute as células em ordem.

Cada etapa deve usar seu ambiente correspondente:1–5 fundamentos de Python;6 NumPy;7–13 pandas;14 visualização;15 arquivos/APIs;16 projeto. Os arquivos pinados das etapas 1,6,7,14,15 e 16 acompanham o pacote. Não instale todas as listas em sequência no mesmo ambiente. A interface Jupyter/VS Code pode ser instalada separadamente.

As consultas ao vivo do 15 são opcionais e desativadas por padrão; os snapshots preservam a reprodução. Consulte [avisos dos dados](DATA-NOTICES.md) e [licenças](../LICENSE-SCOPE.md).
