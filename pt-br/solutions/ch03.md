## Solução do Exercício 01

A lista preserva a sequência dos prazos. O primeiro elemento está no índice 0, o segundo no índice 1 e o último pode ser acessado com -1. Criamos a coleção uma vez e depois consultamos três posições.

``` python
tempos_entrega = [4, 6, 5, 8]
print(tempos_entrega[0])
print(tempos_entrega[1])
print(tempos_entrega[-1])
```

``` text
4
6
8
```

As saídas são 4, 6 e 8 dias. Cada consulta devolve um elemento, não a lista inteira. A ordem foi mantida, sem classificar os prazos do menor para o maior.

<a id="sol-ch03-02"></a>

## Solução do Exercício 02

O limite final do slicing fica fora da seleção. Assim, `[:2]` inclui os índices 0 e 1, enquanto `[2:]` começa no terceiro elemento e segue até o fim.

``` python
print(tempos_entrega[:2])
print(tempos_entrega[2:])
```

``` text
[4, 6]
[5, 8]
```

Obtemos `[4, 6]` e `[5, 8]`. As duas seleções são listas. A lista original continua com quatro elementos, pois apenas consultamos partes dela.

<a id="sol-ch03-03"></a>

## Solução do Exercício 03

Segundo elemento corresponde ao índice 1. Atribuir 7 a essa posição substitui o valor 6; não acrescenta uma observação.

``` python
tempos_entrega[1] = 7
print(tempos_entrega)
```

``` text
[4, 7, 5, 8]
```

A lista passa a ser `[4, 7, 5, 8]`. O número de elementos continua sendo quatro. Usar o índice 2 alteraria o terceiro prazo e responderia a outra tarefa.

<a id="sol-ch03-04"></a>

## Solução do Exercício 04

Depois de acrescentar 3, a lista é `[4, 7, 5, 8, 3]`. Remover 8 deixa `[4, 7, 5, 3]`. O último elemento agora é 3: `pop()` o retira e o devolve para a atribuição.

``` python
tempos_entrega.append(3)
tempos_entrega.remove(8)
prazo_retirado = tempos_entrega.pop()
print(tempos_entrega)
print(prazo_retirado)
```

``` text
[4, 7, 5]
3
```

Permanecem `[4, 7, 5]`, e o valor armazenado é 3. `remove(8)` recebeu um valor, não a posição 8. Para repetir a atividade, recrie os estados anteriores; executar novamente a remoção isolada tentaria retirar um valor que já saiu.

<a id="sol-ch03-05"></a>

## Solução do Exercício 05

Cada função responde a uma pergunta. `len` conta os prazos; `sum` soma suas durações; `min` e `max` identificam extremos. A média divide a soma pela quantidade.

``` python
print(len(tempos_entrega))
print(sum(tempos_entrega))
print(min(tempos_entrega))
print(max(tempos_entrega))
print(sum(tempos_entrega) / len(tempos_entrega))
```

``` text
3
16
4
7
5.333333333333333
```

Há três prazos. Suas durações somam 16 dias, com mínimo de 4, máximo de 7 e média aproximada de 5,33 dias. A soma não significa que uma operação levou 16 dias corridos: isso dependeria de como as entregas se sobrepõem no tempo. Também não significa que cada entrega demorou a média.

<a id="sol-ch03-06"></a>

## Solução do Exercício 06

Este exercício começa uma lista nova. Segunda, terceira e quarta posições correspondem aos índices 1, 2 e 3; por isso, o slicing começa em 1 e para antes de 4. As demais operações resumem a coleção inteira, não apenas o trecho selecionado.

``` python
prazos_desafio = [6, 4, 9, 5, 7, 4]
quantidade_prazos = len(prazos_desafio)
menor_prazo = min(prazos_desafio)
maior_prazo = max(prazos_desafio)
media_prazos = sum(prazos_desafio) / len(prazos_desafio)
prazo_8_presente = 8 in prazos_desafio
valores_centrais = prazos_desafio[1:4]

print(quantidade_prazos)
print(menor_prazo)
print(maior_prazo)
print(media_prazos)
print(prazo_8_presente)
print(valores_centrais)
```

``` text
6
4
9
5.833333333333333
False
[4, 9, 5]
```

São seis observações, com mínimo de 4, máximo de 9 e média aproximada de 5,83 dias. O prazo de 8 dias está ausente, produzindo `False`. A seleção é `[4, 9, 5]`, na ordem recebida. O nome `valores_centrais` não define uma medida estatística: a seleção deste exercício foi estabelecida pelas posições, sem ordenar os valores ou calcular mediana.

<a id="sol-ch03-07"></a>

## Solução do Exercício 07

Criamos uma tupla com dois inteiros. A posição 0 guarda o ano e a posição 1, o trimestre, conforme a convenção declarada no enunciado.

``` python
periodo_balanco = (2026, 2)
print(type(periodo_balanco))
print(periodo_balanco[0])
print(periodo_balanco[1])
```

``` text
<class 'tuple'>
2026
2
```

O tipo é `tuple`, e os valores são 2026 e 2. A referência é o segundo trimestre de 2026, não fevereiro. A forma da tupla, sozinha, não define a unidade do segundo campo.

<a id="sol-ch03-08"></a>

## Solução do Exercício 08

A escolha deve acompanhar o uso esperado. O período é uma referência ordenada que será preservada, enquanto a relação de centros de custo pode receber, perder ou substituir elementos.

Uma resposta possível é: “A tupla representa ano e trimestre em posições definidas e não permite substituir diretamente esses elementos. A lista permite atualizar a relação de centros de custo durante a análise.” Isso justifica a escolha no contexto, sem afirmar que toda informação temporal precisa ser uma tupla.

<a id="sol-ch03-09"></a>

## Solução do Exercício 09

Os atributos têm significados diferentes, por isso os associamos a chaves descritivas. Esta é uma possibilidade: um projeto de modernização da unidade, orçamento de 275000, status Planejado e Equipe de Operações como responsável.

``` python
projeto = {
    "nome": "Modernização da unidade",
    "orcamento": 275000,
    "status": "Planejado",
    "responsavel": "Equipe de Operações"
}
print(projeto)
```

``` text
{'nome': 'Modernização da unidade', 'orcamento': 275000, 'status': 'Planejado', 'responsavel': 'Equipe de Operações'}
```

Cada chave identifica uma informação, e o orçamento permanece numérico. Outros nomes, responsáveis, status e valores são válidos quando coerentes com o pedido. O exemplo de R\$ 275.000 não é um dado obrigatório do enunciado.

<a id="sol-ch03-10"></a>

## Solução do Exercício 10

Consultar orçamento não o altera. Atribuir um valor à chave de status substitui o anterior; atribuir à chave de prazo, ainda inexistente, acrescenta uma informação. Usamos Em execução e dez meses como escolhas ilustrativas.

``` python
print(projeto["orcamento"])
projeto["status"] = "Em execução"
projeto["prazo_meses"] = 10
print(projeto)
```

``` text
275000
{'nome': 'Modernização da unidade', 'orcamento': 275000, 'status': 'Em execução', 'responsavel': 'Equipe de Operações', 'prazo_meses': 10}
```

Nesta resposta, o orçamento exibido é 275000; o novo status e o prazo aparecem no dicionário. Se você escolheu outros valores no Exercício 09, preserve essa continuidade. O critério é realizar corretamente consulta, atualização e inclusão, não copiar as escolhas do exemplo.

<a id="sol-ch03-11"></a>

## Solução do Exercício 11

Os três primeiros métodos permitem inspecionar rótulos, conteúdos e associações. O último responde uma consulta específica, usando a chave do responsável.

``` python
print(projeto.keys())
print(projeto.values())
print(projeto.items())
print(projeto.get("responsavel"))
```

``` text
dict_keys(['nome', 'orcamento', 'status', 'responsavel', 'prazo_meses'])
dict_values(['Modernização da unidade', 275000, 'Em execução', 'Equipe de Operações', 10])
dict_items([('nome', 'Modernização da unidade'), ('orcamento', 275000), ('status', 'Em execução'), ('responsavel', 'Equipe de Operações'), ('prazo_meses', 10)])
Equipe de Operações
```

`keys` mostra os cinco rótulos, incluindo o prazo acrescentado; `values` mostra seus conteúdos; `items` mantém cada chave junto do seu valor. Esses três resultados são views. `get` devolve apenas Equipe de Operações nesta resposta. Seu responsável pode ser outro, conforme o Exercício 09.

<a id="sol-ch03-12"></a>

## Solução do Exercício 12

A pergunta distingue quatro necessidades de representação: alterar uma sequência, preservar uma referência ordenada, consultar por rótulo e identificar valores distintos.

Fornecedores: lista, para acrescentar, remover ou atualizar elementos. Período: tupla, como referência ordenada estável. Contrato: dicionário, para associar atributos a valores. Categorias: set, para manter somente os valores distintos. A justificativa é parte da resposta: reconhecer a sintaxe sem relacioná-la ao problema não basta.

<a id="sol-ch03-13"></a>

## Solução do Exercício 13

As duas listas representam informações correspondentes. Mantemos a ordem do caso e consultamos os nomes com índices 0 e -1. Com quatro elementos, as duas posições centrais são a segunda e a terceira, obtidas por `[1:3]`.

``` python
projetos = ["Expansão", "Automação", "Logística", "Digitalização"]
orcamentos = [320000, 185000, 240000, 150000]
print(projetos[0])
print(projetos[-1])
print(projetos[1:3])
```

``` text
Expansão
Digitalização
['Automação', 'Logística']
```

As saídas são Expansão, Digitalização e `[Automação, Logística]`. Os orçamentos continuam alinhados aos projetos pela posição; o slicing mostrado não modifica nenhuma das listas.

<a id="sol-ch03-14"></a>

## Solução do Exercício 14

Aplicamos as funções à lista numérica e guardamos os extremos. A subtração usa esses dois resultados. Todos os valores têm a mesma unidade monetária.

``` python
total_orcamentos = sum(orcamentos)
menor_orcamento = min(orcamentos)
maior_orcamento = max(orcamentos)
amplitude_orcamentos = maior_orcamento - menor_orcamento
print(total_orcamentos)
print(menor_orcamento)
print(maior_orcamento)
print(amplitude_orcamentos)
```

``` text
895000
150000
320000
170000
```

O total é R\$ 895.000, o mínimo R\$ 150.000 e o máximo R\$ 320.000. A amplitude é R\$ 170.000. As funções retornam números, não nomes de projetos. A amplitude descreve a distância entre extremos; não permite classificar a qualidade, o retorno ou o desempenho dos projetos.

<a id="sol-ch03-15"></a>

## Solução do Exercício 15

O dicionário permite consultar atributos por significado. Mantemos Automação e 185000 como dados do caso. Equipe de Processos, status inicial Planejado e prazo de oito meses são escolhas desta resolução; o status é atualizado para Em execução.

``` python
projeto_automacao = {
    "nome": "Automação",
    "orcamento": 185000,
    "status": "Planejado",
    "responsavel": "Equipe de Processos"
}
projeto_automacao["status"] = "Em execução"
projeto_automacao["prazo_meses"] = 8
print(projeto_automacao)
```

``` text
{'nome': 'Automação', 'orcamento': 185000, 'status': 'Em execução', 'responsavel': 'Equipe de Processos', 'prazo_meses': 8}
```

A saída apresenta o dicionário já atualizado. Não precisamos saber a posição de status para substituí-lo. Outras escolhas coerentes para os atributos abertos são aceitas, desde que a atualização e a inclusão estejam explícitas. Nenhum desses preenchimentos representa informação observada sobre um projeto real.

<a id="sol-ch03-16"></a>

## Solução do Exercício 16

A tupla preserva ano e trimestre em posições definidas. A lista registra os status e suas repetições; o set reúne apenas os valores distintos. Nesta resposta, Em execução aparece duas vezes na lista.

``` python
periodo_referencia = (2026, 3)
status_projetos = [
    'Planejado',
    'Em execução',
    'Concluído',
    'Em execução',
]
status_unicos = set(status_projetos)
print(periodo_referencia)
print(status_unicos)
print("Em execução" in status_unicos)
```

``` text
(2026, 3)
{'Concluído', 'Em execução', 'Planejado'}
True
```

A referência é o terceiro trimestre de 2026. O set contém Planejado, Em execução e Concluído, e o teste retorna `True`. Outra ordem de impressão do set é igualmente correta. O conjunto informa quais status aparecem, mas não quantos projetos estão em cada status nem qual status pertence a cada projeto.

<a id="sol-ch03-17"></a>

## Solução do Exercício 17

O dicionário reúne identificação e coleções. A consulta à chave de projetos devolve uma lista inteira. Para o orçamento inicial, consultamos a chave de orçamentos e então selecionamos o índice 0 da lista obtida.

``` python
portfolio = {
    "empresa": "Nexus",
    "projetos": projetos,
    "orcamentos": orcamentos
}
print(portfolio["projetos"])
print(portfolio["orcamentos"][0])
```

``` text
['Expansão', 'Automação', 'Logística', 'Digitalização']
320000
```

A lista de projetos é preservada, e o orçamento inicial é R\$ 320.000. As listas guardadas são as mesmas já criadas, não cópias independentes. O dicionário não verifica o alinhamento entre elas; a posição 0 continua correspondendo ao primeiro projeto porque mantivemos a ordem.

<a id="sol-ch03-18"></a>

## Solução do Exercício 18

A conclusão deve integrar representação e interpretação. Podemos recuperar os números já calculados, explicar as escolhas e estabelecer o limite da informação disponível. A redação abaixo é uma possibilidade, não um texto obrigatório.

As listas preservaram a ordem dos projetos e orçamentos; o total orçado é R\$ 895.000 e a amplitude entre máximo e mínimo é R\$ 170.000. O dicionário organizou atributos de Automação por significado e reuniu as listas do portfólio, enquanto a tupla registrou ano e trimestre como referência fixa. O set mostrou que existem três status distintos, sem indicar suas frequências. Sem critérios adicionais, esses valores não permitem avaliar o desempenho do portfólio.
