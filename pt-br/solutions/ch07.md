## Solução do Exercício 01

Primeiro disponibilizamos a biblioteca com o alias `pd`. O construtor `pd.Series` recebe a lista e associa um índice aos quatro valores. O atributo `index` permite examinar esses rótulos separadamente, enquanto `type` identifica a estrutura criada.

``` python
import pandas as pd

quantidades = pd.Series([32, 28, 35, 30])
print(quantidades)
print("Índice:", quantidades.index)
print("Tipo:", type(quantidades))
```

``` text
0    32
1    28
2    35
3    30
dtype: int64
Índice: RangeIndex(start=0, stop=4, step=1)
Tipo: <class 'pandas.Series'>
```

A Series contém quatro quantidades e os rótulos automáticos 0 a 3. Esses rótulos não são quantidades adicionais. Como o enunciado não especifica uma unidade física, não devemos inventar produtos, pessoas ou dias para interpretar os valores.

## Solução do Exercício 02

Usamos um dicionário: suas chaves nomeiam as três colunas e suas listas fornecem os valores. As listas têm quatro elementos, na mesma ordem de equipes. `pd.DataFrame` reúne os valores de posições correspondentes em cada linha.

``` python
df_equipes = pd.DataFrame({
    "equipe": ["A", "B", "C", "D"],
    "projetos": [6, 4, 7, 5],
    "orcamento": [120, 95, 140, 110]
})
print(df_equipes)
```

``` text
  equipe  projetos  orcamento
0      A         6        120
1      B         4         95
2      C         7        140
3      D         5        110
```

A tabela tem quatro equipes e três variáveis. A equipe A possui 6 projetos e orçamento de R\$ 120 mil. O orçamento é monetário; projetos é uma contagem. O índice automático não substitui a coluna que identifica a equipe.

``` python
print(df_equipes.head(2))
print(df_equipes.tail(2))
print("Shape:", df_equipes.shape)
print("Colunas:", df_equipes.columns)
print("Tipos:")
print(df_equipes.dtypes)
df_equipes.info()
```

``` text
  equipe  projetos  orcamento
2      C         7        140
```

Cada linha representa uma equipe, e `(4, 3)` significa quatro equipes e três variáveis. `equipe` é textual; projetos e orçamento são inteiros. ## Solução do Exercício 04

Um nome de coluna entre colchetes pede uma Series. Guardamos a seleção em `orcamento`, imprimimos seus valores e usamos `type` para conferir a estrutura.

``` python
orcamento = df_equipes["orcamento"]
print(orcamento)
print(type(orcamento))
```

``` text
0    120
1     95
2    140
3    110
Name: orcamento, dtype: int64
<class 'pandas.Series'>
```

O resultado é uma Series com os orçamentos 120, 95, 140 e 110, em milhares de reais. O índice 0 a 3 preserva a relação com as equipes da tabela original. Uma lista contendo o nome, com colchetes duplos, preservaria um DataFrame.

<a id="sol-ch07-05"></a>

## Solução do Exercício 05

A lista interna contém os dois nomes solicitados, na ordem desejada. Os colchetes externos aplicam essa lista à tabela. `type` permite verificar o resultado, em vez de inferir seu tipo apenas pela impressão.

``` python
selecao = df_equipes[["equipe", "projetos"]]
print(selecao)
print(type(selecao))
```

``` text
  equipe  projetos
0      A         6
1      B         4
2      C         7
3      D         5
<class 'pandas.DataFrame'>
```

A seleção é um DataFrame de quatro linhas e duas colunas. Usar uma lista de nomes mantém a estrutura tabular, mesmo que a lista contenha uma única coluna. A coluna orçamento continua na tabela original, apenas não aparece nesta seleção.

<a id="sol-ch07-06"></a>

## Solução do Exercício 06

No primeiro acesso, `0:2` delimita rótulos e a lista escolhe nomes de colunas. No segundo, os dois slices delimitam posições. A escrita parecida não muda as regras de cada indexador.

``` python
print(df_equipes.loc[0:2, ["equipe", "projetos"]])
print(df_equipes.iloc[0:2, 0:2])
```

``` text
  equipe  projetos
0      A         6
1      B         4
2      C         7
  equipe  projetos
0      A         6
1      B         4
```

`loc` inclui o rótulo final 2 e devolve A, B e C: três linhas. `iloc` exclui a posição final 2 e devolve A e B: duas linhas. Em ambos os casos aparecem as duas variáveis solicitadas, mas por critérios diferentes.

<a id="sol-ch07-07"></a>

## Solução do Exercício 07

Recriamos a tabela fornecida para que o exemplo seja explícito. Procurar o nome `sul` exige seleção por rótulo, com `loc`. A terceira linha ocupa a posição 2, pois a contagem começa em zero; esse pedido usa `iloc`.

``` python
df_regioes = pd.DataFrame(
    {
        "equipe": ["A", "B", "C", "D"],
        "projetos": [6, 4, 7, 5]
    },
    index=["norte", "sul", "leste", "oeste"]
)

selecao_por_rotulo = df_regioes.loc["sul"]
selecao_por_posicao = df_regioes.iloc[2]

print("Linha de rótulo 'sul':")
print(selecao_por_rotulo)
print("Terceira linha, selecionada pela posição 2:")
print(selecao_por_posicao)
```

``` text
Linha de rótulo 'sul':
equipe      B
projetos    4
Name: sul, dtype: object
Terceira linha, selecionada pela posição 2:
equipe      C
projetos    7
Name: leste, dtype: object
```

O rótulo `sul` retorna a equipe B, com 4 projetos. A posição 2 retorna a equipe C, com 7 projetos, cujo rótulo é `leste`. As respostas são diferentes porque as perguntas são diferentes. Nenhuma das seleções é um intervalo; cada uma identifica uma única linha.

## Solução do Exercício 08

Construímos a tabela com cinco produtos e comparamos a coluna inteira de receita com 130. O operador `>=` inclui o limite. Guardar a comparação em um nome permite observar seu resultado antes de usá-lo como filtro.

``` python
import pandas as pd

df_produtos = pd.DataFrame({
    "produto": ["P1", "P2", "P3", "P4", "P5"],
    "receita": [90, 135, 160, 120, 185],
    "custos": [62, 88, 105, 79, 121]
})

condicao_receita = df_produtos["receita"] >= 130
print(condicao_receita)
```

``` text
0    False
1     True
2     True
3    False
4     True
Name: receita, dtype: bool
```

A sequência é False, True, True, False, True. P2, P3 e P5 atendem ao critério de pelo menos R\$ 130 mil. A condição é uma Series booleana, não uma tabela já filtrada.

<a id="sol-ch07-09"></a>

## Solução do Exercício 09

O nome `mascara_receita` comunica qual critério será aplicado. Podemos guardar a condição anterior ou escrevê-la novamente, como nesta solução; os dados e o limite permanecem iguais.

``` python
mascara_receita = df_produtos["receita"] >= 130
print(mascara_receita)
```

``` text
0    False
1     True
2     True
3    False
4     True
Name: receita, dtype: bool
```

A máscara conserva os rótulos 0 a 4 e os mesmos valores booleanos. Ela permite associar cada decisão à linha avaliada. Dar um nome à máscara torna a etapa de seleção mais fácil de ler.

<a id="sol-ch07-10"></a>

## Solução do Exercício 10

Aplicamos a máscara dentro dos colchetes do DataFrame. As linhas associadas a True são copiadas para a seleção nomeada `produtos_selecionados`, com todas as colunas existentes nesse momento.

``` python
produtos_selecionados = df_produtos[mascara_receita]
print(produtos_selecionados)
```

``` text
  produto  receita  custos
1      P2      135      88
2      P3      160     105
4      P5      185     121
```

Permanecem P2, P3 e P5, com índices 1, 2 e 4. Seus valores de receita são 135, 160 e 185 mil reais. A ausência dos índices 0 e 3 não é erro de numeração: o filtro preserva os rótulos das linhas de origem.

<a id="sol-ch07-11"></a>

## Solução do Exercício 11

A subtração usa colunas da mesma tabela, com índices correspondentes. Atribuímos o resultado a uma nova coluna do original, mantendo todos os cinco produtos. A lista de nomes organiza as colunas da impressão.

``` python
df_produtos["lucro"] = df_produtos["receita"] - df_produtos["custos"]
print(df_produtos[["produto", "receita", "custos", "lucro"]])
```

``` text
  produto  receita  custos  lucro
0      P1       90      62     28
1      P2      135      88     47
2      P3      160     105     55
3      P4      120      79     41
4      P5      185     121     64
```

Os lucros simplificados são 28, 47, 55, 41 e 64 mil reais. Esse cálculo descreve a diferença definida no exercício; não acrescenta despesas ou conceitos contábeis ausentes dos dados. A seleção criada no 10 não recebe automaticamente a nova coluna.

<a id="sol-ch07-12"></a>

## Solução do Exercício 12

Selecionamos a mesma coluna em cada chamada e mudamos o método de agregação. O objeto usado é a tabela original, não o subconjunto do filtro. Essa escolha define quais observações entram nos quatro resumos.

``` python
print("Total:", df_produtos["receita"].sum())
print("Média:", df_produtos["receita"].mean())
print("Mínimo:", df_produtos["receita"].min())
print("Máximo:", df_produtos["receita"].max())
```

``` text
Total: 690
Média: 138.0
Mínimo: 90
Máximo: 185
```

O total é 690 mil reais e a média por produto é 138 mil. O mínimo é 90 mil e o máximo é 185 mil. As unidades monetárias acompanham a soma, a média e os extremos; a média não é uma contagem de produtos.

<a id="sol-ch07-13"></a>

## Solução do Exercício 13

A margem é lucro dividido pela receita, multiplicado por 100. Criá-la primeiro garante que o novo subconjunto contenha essa coluna. Depois avaliamos o limite, selecionamos as linhas e aplicamos `mean` às margens do subconjunto. O formato `.2f` controla apenas as casas mostradas no relatório.

``` python
df_produtos["margem_pct"] = df_produtos["lucro"] / df_produtos["receita"] * 100

mascara_desafio = df_produtos["receita"] >= 130
subconjunto = df_produtos[mascara_desafio]
margem_media = subconjunto["margem_pct"].mean()

print(subconjunto[["produto", "receita", "margem_pct"]])
print(f"Média das margens individuais: {margem_media:.2f}%")
```

``` text
  produto  receita  margem_pct
1      P2      135   34.814815
2      P3      160   34.375000
4      P5      185   34.594595
Média das margens individuais: 34.59%
```

P2, P3 e P5 formam o subconjunto; a média de suas margens é aproximadamente 34,59%. Cada produto recebe o mesmo peso nessa média. O indicador não é a razão entre lucro total e receita total. Reutilizar um recorte criado antes da margem deixaria de incluir a coluna necessária.

## Solução do Exercício 14

O dicionário reúne os identificadores dos centros e as três variáveis numéricas. Depois da construção, `head()` mostra até cinco linhas, `shape` informa as dimensões, `columns` lista os nomes e `dtypes` apresenta os tipos.

``` python
import pandas as pd

df_meridian = pd.DataFrame({
    "centro": ["A", "B", "C", "D", "E"],
    "pedidos": [1250, 980, 1420, 1100, 1330],
    "entregues": [1180, 910, 1365, 1040, 1245],
    "custo": [84000, 72000, 91000, 78000, 86500]
})

print(df_meridian.head())
print("Shape:", df_meridian.shape)
print("Colunas:", df_meridian.columns)
print(df_meridian.dtypes)
```

``` text
  centro  pedidos  entregues  custo
0      A     1250       1180  84000
1      B      980        910  72000
2      C     1420       1365  91000
3      D     1100       1040  78000
4      E     1330       1245  86500
Shape: (5, 4)
Colunas: Index(['centro', 'pedidos', 'entregues', 'custo'], dtype='str')
centro         str
pedidos      int64
entregues    int64
custo        int64
dtype: object
```

Há cinco centros e quatro variáveis, portanto `(5, 4)`. Cada linha representa um centro logístico. Pedidos e entregues são contagens; custo é um valor em reais. A coluna centro é textual. A estrutura não informa causas nem um período de observação.

## Solução do Exercício 15

Precisamos identificar o centro e observar os dois volumes. Por isso selecionamos `centro`, `pedidos` e `entregues` com uma lista de nomes. A coluna custo não é necessária para essa pergunta específica.

``` python
volumes = df_meridian[["centro", "pedidos", "entregues"]]
print(volumes)
```

``` text
  centro  pedidos  entregues
0      A     1250       1180
1      B      980        910
2      C     1420       1365
3      D     1100       1040
4      E     1330       1245
```

A tabela selecionada permite comparar pedidos e entregas em cada centro sem perder sua identificação. Uma seleção substantiva parte da pergunta e escolhe as variáveis que ajudam a respondê-la. Ela não apaga a coluna custo da base original.

## Solução do Exercício 16

A diferença entre pedidos e entregas fornece a quantidade não entregue. A razão entre entregues e pedidos, multiplicada por 100, fornece a taxa de atendimento de cada centro. Todos os centros têm pedidos positivos, permitindo a divisão nos dados apresentados.

``` python
df_meridian["nao_entregues"] = df_meridian["pedidos"] - df_meridian["entregues"]
df_meridian["taxa_atendimento_pct"] = (
    df_meridian["entregues"] / df_meridian["pedidos"] * 100
)

print(df_meridian)
```

``` text
  centro  pedidos  entregues  custo  nao_entregues  taxa_atendimento_pct
0      A     1250       1180  84000             70             94.400000
1      B      980        910  72000             70             92.857143
2      C     1420       1365  91000             55             96.126761
3      D     1100       1040  78000             60             94.545455
4      E     1330       1245  86500             85             93.609023
```

Os não entregues são 70, 70, 55, 60 e 85. As taxas são aproximadamente 94,40%, 92,86%, 96,13%, 94,55% e 93,61%. Quantidade e proporção respondem a perguntas diferentes. A diferença não identifica atraso: nenhum prazo foi informado.

## Solução do Exercício 17

Comparamos a coluna criada no 16 com 95 e guardamos a Series booleana em uma máscara. O operador `<` é estrito: uma taxa exatamente igual a 95% não entraria. O filtro usa os valores completos, sem arredondá-los antes da comparação.

``` python
mascara_taxa = df_meridian["taxa_atendimento_pct"] < 95
centros_abaixo = df_meridian[mascara_taxa]

print(mascara_taxa)
print(centros_abaixo[["centro", "taxa_atendimento_pct"]])
```

``` text
0     True
1     True
2    False
3     True
4     True
Name: taxa_atendimento_pct, dtype: bool
  centro  taxa_atendimento_pct
0      A             94.400000
1      B             92.857143
3      D             94.545455
4      E             93.609023
```

A máscara é True, True, False, True, True. Os centros A, B, D e E estão abaixo do limite. C fica fora porque sua taxa supera 95%. Esse resultado descreve o critério aplicado, sem explicar por que as taxas diferem.

## Solução do Exercício 18

A expressão “três primeiras” se refere à ordem, portanto escolhemos `iloc[0:3]`. O limite 3 fica excluído, deixando posições 0, 1 e 2. Na tabela resultante, selecionamos por nome as quatro variáveis pedidas.

``` python
tres_primeiros = df_meridian.iloc[0:3]

resultado = tres_primeiros[
    ["centro", "pedidos", "entregues", "taxa_atendimento_pct"]
]

print(resultado)
```

``` text
  centro  pedidos  entregues  taxa_atendimento_pct
0      A     1250       1180             94.400000
1      B      980        910             92.857143
2      C     1420       1365             96.126761
```

A, B e C aparecem porque ocupam as três primeiras posições. Não houve ordenação por taxa, custo ou volume: não são os três melhores centros. A solução combina seleção posicional de linhas com seleção nominal de colunas.

## Solução do Exercício 19

Somamos pedidos e entregues na base completa e reutilizamos a coluna `nao_entregues`. Para a taxa global, dividimos entregas totais por pedidos totais; cada pedido entra no denominador. Para custo médio por centro, aplicamos `mean` à coluna custo. A formatação das duas últimas linhas organiza a apresentação e não altera os cálculos.

``` python
pedidos_totais = df_meridian["pedidos"].sum()
entregas_totais = df_meridian["entregues"].sum()
nao_entregues_totais = df_meridian["nao_entregues"].sum()
taxa_global = entregas_totais / pedidos_totais * 100
custo_medio = df_meridian["custo"].mean()

print("Relatório Meridian")
print("Pedidos totais:", pedidos_totais)
print("Entregas totais:", entregas_totais)
print("Não entregues:", nao_entregues_totais)
print(f"Taxa global: {taxa_global:.2f}%")
print(f"Custo médio observado: R$ {custo_medio:,.2f}")
```

``` text
Relatório Meridian
Pedidos totais: 6080
Entregas totais: 5740
Não entregues: 340
Taxa global: 94.41%
Custo médio observado: R$ 82,300.00
```

O relatório reúne 6.080 pedidos, 5.740 entregas e 340 não entregues. A taxa global é aproximadamente 94,41%, calculada pelos totais, e não pela média simples das cinco taxas. O custo médio por centro é R\$ 82.300; não é custo por pedido. A, B, D e E ficaram abaixo de 95%, mas os dados não identificam causas, prazos ou um período mensal. Na saída, a formatação `:,.2f` usa vírgula de milhares e ponto decimal do Python.
