## Solução do Exercício 01

Primeiro comparamos cada indicador com sua própria meta. A margem não alcança 30%, enquanto a receita supera R\$ 200.000. Nesta resposta, aplicamos `not` à comparação da receita.

``` python
margem = 28
meta_margem = 30
receita = 210000
meta_receita = 200000
print(margem >= meta_margem and receita >= meta_receita)
print(margem >= meta_margem or receita >= meta_receita)
print(not (receita >= meta_receita))
```

``` text
False
True
False
```

`and` resulta em `False` porque um dos critérios falha. `or` resulta em `True` porque a receita atende ao critério. A comparação da receita é verdadeira; sua negação é falsa. Se você escolheu negar a comparação da margem, obter `True` também é correto, desde que explique a escolha.

## Solução do Exercício 02

A ação depende de uma comparação estrita: o estoque precisa estar abaixo de 40. O cabeçalho termina em dois-pontos; a impressão pertence ao bloco recuado.

``` python
estoque = 35
estoque_minimo = 40
if estoque < estoque_minimo:
    print("Repor estoque.")
```

``` text
Repor estoque.
```

Como 35 é menor que 40, a mensagem aparece. O código apenas sinaliza a necessidade de reposição; ele não aumenta o estoque. Se o estoque fosse exatamente o mínimo, esse `if` não produziria a mensagem.

## Solução do Exercício 03

Representamos as taxas na mesma escala: 4.2 e 5, ambas em porcentagem. `<=` inclui a igualdade; `else` reúne as situações que ultrapassam o limite.

``` python
inadimplencia = 4.2
limite = 5
if inadimplencia <= limite:
    print("Dentro do limite.")
else:
    print("Fora do limite.")
```

``` text
Dentro do limite.
```

O programa escolhe “Dentro do limite.” porque 4,2 é menor que 5. Esse resultado aplica a regra fornecida; não constitui uma avaliação geral da situação financeira.

## Solução do Exercício 04

O teste de 100 vem primeiro, pois todo valor que o satisfaz também satisfaz o teste de 80. A cadeia deve selecionar a categoria mais alta aplicável segundo a regra.

``` python
produtividade = 92
if produtividade >= 100:
    print("Alta")
elif produtividade >= 80:
    print("Adequada")
else:
    print("Atenção")
```

``` text
Adequada
```

Com 92 unidades, o primeiro teste falha e o segundo passa. Se começássemos por `>= 80`, valores de 100 ou mais seriam classificados prematuramente como adequados. Um resultado correto apenas para 92 não bastaria para validar a ordem da regra.

<a id="sol-ch04-05"></a>

## Solução do Exercício 05

A elegibilidade exige simultaneamente as duas comparações. Usamos `and` no cabeçalho e mantemos a mensagem dentro do bloco.

``` python
retorno = 14
risco = 5
if retorno >= 12 and risco <= 6:
    print("Proposta elegível.")
```

``` text
Proposta elegível.
```

14 satisfaz o limite inferior de 12 e 5 satisfaz o limite superior de 6. Portanto, a proposta atende à regra didática. A conclusão se restringe à elegibilidade definida no enunciado; não é uma recomendação de investimento.

## Solução do Exercício 06

Repetimos a mesma cadeia em três células, mudando apenas o prazo. Isso permite observar cada resposta sem antecipar os laços de repetição. O teste `> 20` precede `> 10`, pois os valores críticos também são maiores que dez.

``` python
prazo = 7
if prazo > 20:
    print("Crítico")
elif prazo > 10:
    print("Atenção")
else:
    print("Controlado")
```

``` text
Controlado
```

``` python
prazo = 15
if prazo > 20:
    print("Crítico")
elif prazo > 10:
    print("Atenção")
else:
    print("Controlado")
```

``` text
Atenção
```

``` python
prazo = 25
if prazo > 20:
    print("Crítico")
elif prazo > 10:
    print("Atenção")
else:
    print("Controlado")
```

``` text
Crítico
```

As classificações são Controlado, Atenção e Crítico, respectivamente. Em cada célula, somente o primeiro ramo verdadeiro é executado. Exatamente 20 dias ainda pertence à faixa de atenção, e exatamente 10 pertence à faixa controlada, de acordo com as desigualdades estritas.

## Solução do Exercício 07

O nome `valor` recebe um elemento por passagem. A f-string insere esse elemento na mensagem. Como o `print` está dentro do laço, há uma linha para cada observação.

``` python
valores = [12, 15, 11, 18]
for valor in valores:
    print(f"Valor: {valor}")
```

``` text
Valor: 12
Valor: 15
Valor: 11
Valor: 18
```

A ordem permanece 12, 15, 11 e 18. O laço não ordena a lista nem muda seus elementos. A variável da passagem contém um valor, não uma posição.

<a id="sol-ch04-08"></a>

## Solução do Exercício 08

Inicializamos as duas variáveis antes do percurso. Em cada passagem, o total recebe o valor observado, enquanto o contador recebe apenas uma unidade. A lista `valores` precisa estar definida pelo Exercício 07.

``` python
total = 0
contador = 0
for valor in valores:
    total = total + valor
    contador = contador + 1
print(total, contador)
print(sum(valores), len(valores))
```

``` text
56 4
56 4
```

As duas linhas apresentam 56 e 4. A primeira resulta do procedimento explícito; a segunda, das funções nativas. A concordância confere o cálculo para esta lista. Reiniciar as variáveis em zero é necessário para não acumular o resultado de uma execução anterior.

## Solução do Exercício 09

O início deve ser 1. Como o limite final de `range` é excluído, usamos 7 para que 6 seja o último valor percorrido.

``` python
for periodo in range(1, 7):
    print(periodo)
```

``` text
1
2
3
4
5
6
```

São seis passagens. `range(6)` também produziria seis números, mas começaria em zero e terminaria em cinco, contrariando o enunciado.

## Solução do Exercício 10

O teste ocorre antes de cada passagem. A impressão precede a redução, de modo que vemos o estado positivo que permitiu entrar no bloco.

``` python
pendencias = 4
while pendencias > 0:
    print(pendencias)
    pendencias = pendencias - 1
```

``` text
4
3
2
1
```

Depois de imprimir 1, a atribuição reduz as pendências a zero. O próximo teste falha e encerra a repetição. Sem `pendencias = pendencias - 1`, o estado permaneceria em quatro e o laço não terminaria por essa condição.

<a id="sol-ch04-11"></a>

## Solução do Exercício 11

No primeiro trecho, o negativo encerra o percurso. No segundo, encerra apenas a passagem atual. Colocar o `print` depois do teste faz com que o negativo não seja apresentado em nenhum dos casos.

``` python
valores = [8, 12, -1, 15]
for valor in valores:
    if valor < 0:
        break
    print(valor)
```

``` text
8
12
```

``` python
valores = [8, -1, 12, -2, 15]
for valor in valores:
    if valor < 0:
        continue
    print(valor)
```

``` text
8
12
15
```

O primeiro trecho mostra 8 e 12; não chega ao 15. O segundo mostra 8, 12 e 15, pois segue adiante depois de cada negativo. As listas permanecem intactas; o que muda é o caminho de execução.

## Solução do Exercício 12

A condição deve controlar as duas atualizações. Tanto o contador quanto o acumulador ficam dentro do `if`; as inicializações ficam antes do `for`, e as impressões, depois dele.

``` python
notas = [72, 88, 91, 65, 84]
quantidade = 0
total_selecionado = 0
for nota in notas:
    if nota >= 80:
        quantidade = quantidade + 1
        total_selecionado = total_selecionado + nota
print(quantidade)
print(total_selecionado)
```

``` text
3
263
```

Contribuem 88, 91 e 84: três valores cuja soma é 263. Os valores 72 e 65 são percorridos, mas não atualizam os resultados. O contador mede quantos foram selecionados; o acumulador mede a soma desse subconjunto.

## Solução do Exercício 13

Começamos pelo limite de cinco minutos. Só chegamos ao `elif` quando a espera é maior que cinco; testar `<= meta` nesse ponto identifica a faixa intermediária. O `else` cobre tempos acima de sete minutos.

``` python
tempos_espera = [4, 12, 7, 3, 15, 8, 5, 11, 6, 2]
meta = 7
for tempo in tempos_espera:
    if tempo <= 5:
        print(f'{tempo}: atendimento rápido')
    elif tempo <= meta:
        print(f'{tempo}: dentro da meta, acima de 5 minutos')
    else:
        print(f'{tempo}: acima da meta')
```

``` text
4: atendimento rápido
12: acima da meta
7: dentro da meta, acima de 5 minutos
3: atendimento rápido
15: acima da meta
8: acima da meta
5: atendimento rápido
11: acima da meta
6: dentro da meta, acima de 5 minutos
2: atendimento rápido
```

As faixas são exclusivas. Os atendimentos rápidos também cumprem a meta geral de sete minutos, mas recebem sua própria categoria. Se o primeiro teste fosse `<= 7`, ele absorveria os rápidos e impediria essa separação. A impressão mantém a ordem dos dez registros.

## Solução do Exercício 14

A soma de tempos deve incluir todos os registros, por isso sua atualização fica dentro do `for` e antes da classificação. Cada ramo incrementa apenas o contador de sua faixa. Reinicializamos tudo para que o novo percurso não duplique resultados anteriores.

``` python
tempos_espera = [4, 12, 7, 3, 15, 8, 5, 11, 6, 2]
meta = 7
quantidade_rapida = 0
quantidade_dentro_meta = 0
quantidade_acima_meta = 0
total = 0

for tempo in tempos_espera:
    total = total + tempo
    if tempo <= 5:
        quantidade_rapida = quantidade_rapida + 1
        print(f"{tempo}: atendimento rápido")
    elif tempo <= meta:
        quantidade_dentro_meta = quantidade_dentro_meta + 1
        print(f"{tempo}: dentro da meta, acima de 5 minutos")
    else:
        quantidade_acima_meta = quantidade_acima_meta + 1
        print(f"{tempo}: acima da meta")
```

``` text
4: atendimento rápido
12: acima da meta
7: dentro da meta, acima de 5 minutos
3: atendimento rápido
15: acima da meta
8: acima da meta
5: atendimento rápido
11: acima da meta
6: dentro da meta, acima de 5 minutos
2: atendimento rápido
```

Ao final, as variáveis guardam 4 atendimentos rápidos, 2 na faixa intermediária, 4 acima da meta e soma de 73 minutos. As mensagens individuais repetem a classificação do item anterior; os totais ficam armazenados para o próximo cálculo. Os 73 minutos somam esperas de pessoas distintas e não medem necessariamente a duração de operação da central.

## Solução do Exercício 15

Somar os três contadores fornece o denominador comum. Dividimos a soma de tempos por essa quantidade para obter a média e dividimos a contagem acima da meta pelo mesmo total, multiplicando por 100 para obter o percentual.

``` python
quantidade = (
    quantidade_rapida + quantidade_dentro_meta + quantidade_acima_meta
)
media = total / quantidade
percentual_acima_meta = quantidade_acima_meta / quantidade * 100

print(quantidade)
print(f"{media:.2f}")
print(f"{percentual_acima_meta:.2f}%")
```

``` text
10
7.30
40.00%
```

Há 10 atendimentos, média de 7,30 minutos e 40% acima da meta. O formato `:.2f` determina a apresentação com duas casas. A divisão é válida porque o total é positivo. O resultado médio não informa sozinho a distribuição entre faixas; precisamos também das contagens.

<a id="sol-ch04-16"></a>

## Solução do Exercício 16

O contador começa em zero. A condição mantém explícitos o descumprimento da meta e o limite adicional inclusivo de dez minutos. Usamos a mesma lista e a mesma meta definidas no caso.

``` python
esperas_elevadas = 0

for tempo in tempos_espera:
    if tempo > meta and tempo >= 10:
        esperas_elevadas = esperas_elevadas + 1

print(esperas_elevadas)
```

``` text
3
```

As esperas de 12, 15 e 11 minutos satisfazem a regra, produzindo três ocorrências. A espera de 8 ultrapassa a meta, mas não chega a dez. Com a meta fixa em sete, todo valor de pelo menos dez já a ultrapassa: o primeiro teste é redundante numericamente, embora explicite os dois critérios do enunciado. Dez seria incluído pela regra, mesmo sem haver esse valor na lista.

<a id="sol-ch04-17"></a>

## Solução do Exercício 17

O relatório reúne valores já calculados. Cada f-string coloca uma variável na mensagem apropriada; média e percentual usam duas casas. A unidade “minutos” distingue a média de uma contagem.

``` python
print("Central de Atendimento Prisma")
print(f"Total: {quantidade}")
print(f"Atendimentos rápidos: {quantidade_rapida}")
print(f"Dentro da meta, acima de 5 minutos: {quantidade_dentro_meta}")
print(f"Acima da meta: {quantidade_acima_meta}")
print(f"Média: {media:.2f} minutos")
print(f"Percentual acima da meta: {percentual_acima_meta:.2f}%")
print(f"Esperas particularmente elevadas: {esperas_elevadas}")
```

``` text
Central de Atendimento Prisma
Total: 10
Atendimentos rápidos: 4
Dentro da meta, acima de 5 minutos: 2
Acima da meta: 4
Média: 7.30 minutos
Percentual acima da meta: 40.00%
Esperas particularmente elevadas: 3
```

A linha intermediária mostra dois atendimentos, mas o total dentro da meta geral é seis: quatro rápidos mais dois intermediários. Esses seis não formam uma quarta faixa a ser somada às demais. As três faixas exclusivas somam dez, e as três esperas particularmente elevadas são um subconjunto dos quatro atendimentos acima da meta.

<a id="sol-ch04-18"></a>

## Solução do Exercício 18

Uma conclusão deve relacionar as medidas e restringir-se aos dez registros. A resposta abaixo tem quatro frases; outras formulações são válidas se preservarem números, unidades e limites.

Nos dez atendimentos observados, quatro foram rápidos, dois ficaram acima de cinco e até sete minutos e quatro ultrapassaram a meta de sete minutos. A média foi de 7,30 minutos, enquanto 40% dos atendimentos ficaram acima da meta. Três das quatro esperas acima da meta chegaram a pelo menos dez minutos, formando o subconjunto de esperas particularmente elevadas. Esses resultados descrevem os registros fornecidos, sem identificar causas ou estabelecer o desempenho global da central.
