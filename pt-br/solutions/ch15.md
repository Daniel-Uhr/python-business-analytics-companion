## Solução do Exercício 01

Os dois arquivos são autorais e didáticos. O CSV organiza uma filial em um mês por linha. A pasta Excel contém duas tabelas: `unidades`, com uma unidade operacional por linha, e `metas`, com uma unidade em um ano por linha. O formato descreve a representação; a unidade descreve o significado do registro. São informações distintas e ambas precisam ser documentadas.

Receita e meta de receita representam reais em unidades monetárias. A margem do CSV é percentual; a margem-alvo do Excel é fracionária. Os arquivos não descrevem empresas reais.

## Solução do Exercício 21

Prontidão precisa de um uso declarado. O CSV está organizado para uma análise didática das observações empresariais disponíveis, com cobertura parcial de março. O IBC-Br está organizado para descrever o período fixo da versão recebida. Essas duas conclusões não autorizam juntar as bases ou inferir causas.

``` python
prontidao = {
    'filiais': 'pronta para análise didática; março parcial; dados fictícios',
    'IBC-Br': 'pronta para descrição de 2023-2024; NSA; sujeito a revisões'
}
for base, conclusao in prontidao.items():
    print(f'{base}: {conclusao}')
```

``` text
filiais: pronta para análise didática; março parcial; dados
  fictícios
IBC-Br: pronta para descrição de 2023-2024; NSA; sujeito a revisões
```

A ficha torna explícito o limite de cada decisão. Uma nova pergunta pode exigir outro conjunto, outro período ou outras validações, mesmo que a importação atual esteja correta.

## Solução do Exercício 22

Uma entrega possível reúne as etapas 16–21 sem repeti-las como operações desconectadas. A decisão de usar `sep=";"` e `decimal=","` deriva do formato do CSV. A chave filial–mês deriva da unidade observada. A verificação dos 24 meses deriva do período declarado da série. Registrar a aquisição original e reservar um nome novo deriva da necessidade de reproduzir a versão analisada.

Essas são quatro decisões justificadas, superando o mínimo de três. O resultado inclui as fontes, as tabelas importadas, as conversões, os diagnósticos, a ficha de proveniência e duas conclusões de prontidão. A manutenção das bases separadas também é justificada: um índice nacional não é uma observação própria de cada filial.

Não existe uma única organização correta. Outras escolhas são aceitáveis se forem coerentes com as fontes e preservarem os oito itens exigidos. A autonomia está na justificativa e na qualidade do percurso; não em alterar os dados para obter um resultado esperado.
