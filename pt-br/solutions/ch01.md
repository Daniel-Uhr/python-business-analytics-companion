# Resoluções — Capítulo 1 — Python, Jupyter e o pensamento computacional

[Índice do idioma](../README.md) · [Notebook do estudante](../ch01-student.ipynb)

Tente os exercícios antes de consultar as resoluções. Questões abertas admitem outras respostas justificadas.

Este capítulo reúne as resoluções dos 23 exercícios do suplemento do Capítulo 1. Nos itens abertos, a resposta apresentada é uma possibilidade: o critério é preservar o sentido, a organização solicitada e a interpretação dos dados.

<a id="sol-ch01-01"></a>

## Solução do Exercício 01

O título identifica o documento para quem o lê. Escreva a marcação em uma célula Markdown e renderize-a; o espaço depois de `#` separa o marcador do texto. Não use uma célula Code para produzir esse título.

``` markdown
# Minha primeira análise em Python
```

O resultado é um título principal, não uma saída de cálculo.

<a id="sol-ch01-02"></a>

## Solução do Exercício 02

Uma pergunta útil explicita o que desejamos comparar ou conhecer. A resposta abaixo indica um objeto, uma medida implícita de vendas e um período. Outras perguntas claras e relacionadas a dados também são válidas.

Quais produtos venderam mais no último mês?

Em uma análise real, também precisaríamos esclarecer se “mais” se refere a quantidade, receita ou outra medida.

<a id="sol-ch01-03"></a>

## Solução do Exercício 03

Cada item da lista apresenta uma pergunta. O marcador organiza o texto e não executa uma operação. Esta é uma possibilidade de resposta; perguntas alternativas podem cumprir o mesmo objetivo.

``` markdown
- Qual filial fatura mais?
- Quais custos cresceram?
- Qual produto vendeu mais?
```

A lista contém três itens. O período e a medida devem ser definidos quando cada pergunta se transformar em uma análise concreta.

<a id="sol-ch01-04"></a>

## Solução do Exercício 04

O sinal `+` solicita a soma dos dois valores. Como a expressão é a última da célula, o ambiente interativo apresenta seu resultado.

``` python
150 + 75
```

``` text
225
```

A saída `225` é o resultado da soma. Aqui não foi necessário chamar `print()`.

<a id="sol-ch01-05"></a>

## Solução do Exercício 05

No notebook do estudante, esta célula começa como Code. Nesse contexto, a linha iniciada por `#` é comentário e não produz um título. Selecione Markdown no controle de tipo da célula e renderize-a.

``` markdown
## Célula convertida para Markdown
```

Depois da conversão, `##` cria um subtítulo. O conteúdo textual é o mesmo, mas o tipo da célula determina como o ambiente o interpreta.

<a id="sol-ch01-06"></a>

## Solução do Exercício 06

A escolha decorre da finalidade. O que comunica e organiza a análise pertence à narrativa; o que deve ser executado pertence ao código.

- Título: Markdown.
- Cálculo: Code.
- Interpretação: Markdown.
- Comando Python: Code.

Uma conta pode ser discutida em Markdown, mas sua execução acontece na célula Code.

<a id="sol-ch01-07"></a>

## Solução do Exercício 07

A tarefa combina organização e execução. O título identifica a análise; uma célula separada realiza a subtração.

``` markdown
# Análise de custos
```

``` python
90000 - 62000
```

``` text
28000
```

A diferença calculada é `28000`. O título não substitui a expressão, e a expressão não substitui a identificação do documento.

<a id="sol-ch01-08"></a>

## Solução do Exercício 08

O enunciado identifica a ordem da comparação: planejado menos realizado. Por isso, o primeiro número da expressão é 210000.

``` python
210000 - 148000
```

``` text
62000
```

A diferença é R\$ 62.000: as vendas realizadas ficaram R\$ 62.000 abaixo do planejado. Um resultado positivo nesta ordem não significa desempenho acima da meta.

<a id="sol-ch01-09"></a>

## Solução do Exercício 09

Passamos o texto entre aspas como argumento da função. As aspas delimitam o texto no código e não aparecem na mensagem impressa.

``` python
print("Análise mensal")
```

``` text
Análise mensal
```

A saída foi solicitada explicitamente por `print()`.

<a id="sol-ch01-10"></a>

## Solução do Exercício 10

A expressão dentro dos parênteses é avaliada antes de sua apresentação. Não a colocamos entre aspas, porque queremos calcular a diferença, e não imprimir o texto da expressão.

``` python
print(210000 - 148000)
```

``` text
62000
```

A saída `62000` vem de uma chamada explícita de impressão.

<a id="sol-ch01-11"></a>

## Solução do Exercício 11

O comentário deve esclarecer a ordem e a finalidade da conta. É possível usar outras palavras, desde que permaneçam coerentes com planejado menos realizado.

``` python
# Diferença entre vendas planejadas e realizadas
210000 - 148000
```

``` text
62000
```

O comentário não muda o resultado `62000`; ele ajuda a preservar seu significado.

<a id="sol-ch01-12"></a>

## Solução do Exercício 12

Enquanto a linha está comentada, ela não é executada. Ao transformá-la em uma instrução, precisamos completar o parêntese aberto depois de `print`. As aspas já delimitam corretamente a mensagem.

``` python
print("Receita mensal")
```

``` text
Receita mensal
```

A solução imprime a mensagem. O objetivo é identificar e corrigir a sintaxe, não deixar um erro ativo no notebook inicial.

<a id="sol-ch01-13"></a>

## Solução do Exercício 13

A primeira linha chama uma função de impressão. A segunda é a última expressão da célula, cujo valor é apresentado pelo ambiente interativo.

``` python
print("Lucro mensal")
120000 - 85000
```

``` text
Lucro mensal
35000
```

`Lucro mensal` é impresso por `print()`; `35000` é exibido como valor da última expressão. A mensagem é apenas um rótulo: não estabelece, por si só, que a diferença seja lucro contábil completo.

<a id="sol-ch01-14"></a>

## Solução do Exercício 14

A consulta mostra que podemos informar o número e a quantidade de casas. Usamos três como segundo argumento. A ajuda pode variar em apresentação entre versões, mas deve permitir identificar essa finalidade.

``` python
help(round)
```

A ajuda do próprio Python aparece em inglês:

``` text
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None.  Otherwise
    the return value has the same type as the number.  ndigits may be negative.
```

``` python
round(17.43891, 3)
```

``` text
17.439
```

O resultado arredondado é `17.439`. Ele aproxima o valor inicial com a precisão solicitada.

<a id="sol-ch01-15"></a>

## Solução do Exercício 15

A expressão calcula a diferença, compara-a com 250000 e converte a proporção em percentual. Passamos essa expressão diretamente a `round`, com segundo argumento igual a dois.

``` python
round((250000 - 172000) / 250000 * 100, 2)
```

``` text
31.2
```

A saída é `31.2`, equivalente à escrita percentual 31,20%. O arredondamento numérico não obriga a exibição de um zero final.

<a id="sol-ch01-16"></a>

## Solução do Exercício 16

Antes dos cálculos, identificamos o caso e os valores usados. Esse contexto permite que outra pessoa interprete as expressões seguintes sem reconstruir o enunciado.

``` markdown
# Análise mensal — Loja Horizonte
## Dados
- Receita: R$ 185.000
- Custos: R$ 126.000
- Meta de margem: 30%
```

Os valores são didáticos. A meta é percentual; receita e custos são valores monetários.

<a id="sol-ch01-17"></a>

## Solução do Exercício 17

A pergunta define a ordem da subtração: receita menos custos. Usamos diretamente os números informados no cenário.

``` python
185000 - 126000
```

``` text
59000
```

A diferença simplificada é R\$ 59.000. Ela compara as grandezas fornecidas e não corresponde necessariamente ao lucro contábil completo.

<a id="sol-ch01-18"></a>

## Solução do Exercício 18

Dividimos a diferença pela receita para obter uma proporção. Multiplicamos por 100 porque a meta foi expressa em percentual; comparar unidades compatíveis é necessário.

``` python
(185000 - 126000) / 185000 * 100
```

``` text
31.891891891891895
```

A saída `31.891891891891895` corresponde a aproximadamente 31,89% da receita.

<a id="sol-ch01-19"></a>

## Solução do Exercício 19

Colocamos toda a expressão da margem no primeiro argumento de `round`, para arredondar o resultado da operação, e usamos dois no segundo argumento.

``` python
round((185000 - 126000) / 185000 * 100, 2)
```

``` text
31.89
```

O valor arredondado é `31.89`; no texto em português, escrevemos aproximadamente 31,89%.

<a id="sol-ch01-20"></a>

## Solução do Exercício 20

A primeira chamada imprime uma mensagem; a segunda imprime o resultado numérico. Cada chamada apresenta sua saída em uma linha.

``` python
print("Resultado da análise")
print(round((185000 - 126000) / 185000 * 100, 2))
```

``` text
Resultado da análise
31.89
```

A saída associa a mensagem ao valor `31.89`. A interpretação percentual ainda precisa ser explicitada no texto.

<a id="sol-ch01-21"></a>

## Solução do Exercício 21

Escolhemos a margem e registramos o significado da expressão. Outros comentários são válidos quando descrevem corretamente o cálculo ao qual se referem.

``` python
# Margem percentual simplificada
round((185000 - 126000) / 185000 * 100, 2)
```

``` text
31.89
```

O comentário documenta a operação, sem alterar a saída `31.89`.

<a id="sol-ch01-22"></a>

## Solução do Exercício 22

A comparação deve usar o mesmo indicador e a mesma unidade da meta. A margem calculada é percentual, assim como a meta de 30%.

A margem simplificada foi aproximadamente 31,89%, portanto superou a meta de 30%. Com base nesse indicador e nos dados informados, a meta foi atingida.

Essa conclusão responde à pergunta do caso; ela não demonstra, por si só, desempenho satisfatório em todas as dimensões do negócio.

<a id="sol-ch01-23"></a>

## Solução do Exercício 23

A conclusão deve reunir os resultados essenciais e responder à decisão solicitada. Podemos usar outra redação, desde que valores, unidades e interpretação sejam preservados.

``` markdown
## Conclusão
A Loja Horizonte apresentou diferença de R$ 59.000 entre receita e custos. A margem simplificada foi aproximadamente 31,89%, superando a meta de 30%. Com base nesse indicador e nos dados informados, a meta foi atingida.
```

A resposta contém três frases. Ela não afirma que a diferença corresponde ao lucro contábil completo nem recomenda uma ação não sustentada pelo caso.
