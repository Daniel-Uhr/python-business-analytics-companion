## Preparação do Bloco A

Importamos pandas e construímos a base do bloco. Cada lista fornece uma coluna; valores na mesma posição formam a mesma observação. Os dados e suas unidades foram definidos na preparação do suplemento.

``` python
import pandas as pd

df_unidades = pd.DataFrame({
    "unidade": ["U1", "U2", "U3", "U4", "U5", "U6"],
    "regiao": ["Sul", "Sudeste", "Sul", "Centro-Oeste", "Sudeste", "Norte"],
    "receita": [180, 145, 210, 168, 195, 132],
    "custos": [125, 108, 152, 121, 138, 99]
})
print(df_unidades)
```

``` text

0      U1           Sul      180     125
1      U2       Sudeste      145     108
2      U3           Sul      210     152
3      U4  Centro-Oeste      168     121
4      U5       Sudeste      195     138
5      U6         Norte      132      99
```

## Solução do Exercício 01

Primeiro, comparamos cada receita com 180. Como os valores da base estão em milhares de reais, esse limite representa R\$ 180.000. A máscara seleciona linhas; a lista passada depois da vírgula em `.loc` escolhe as duas colunas solicitadas.

``` python
mascara = df_unidades["receita"] >= 180
resultado = df_unidades.loc[mascara, ["unidade", "receita"]]
print(resultado)
```

``` text
  unidade  receita
0      U1      180
2      U3      210
4      U5      195
```

U1, U3 e U5 permanecem, com receitas de 180, 210 e 195 milhares de reais. U1 mostra que a igualdade é incluída. Os rótulos 0, 2 e 4 preservam a identificação das linhas da base.

## Solução do Exercício 02

``` python
condicao_custos = df_unidades["custos"] < 120
```

Os valores são False, True, False, False, False e True. U2 e U6 têm custos abaixo de 120 milhares de reais. `True` significa que a linha satisfaz esse critério; não é uma avaliação geral da unidade. O limite 120 não seria incluído.

## Solução do Exercício 03

Os critérios se referem à mesma linha: receita suficiente e custos dentro do limite. Construí-los separadamente permite conferir cada pergunta antes de aplicar `&`. As duas Series mantêm o índice de `df_unidades`.

``` python
condicao_receita = df_unidades["receita"] >= 170
condicao_custos = df_unidades["custos"] <= 140
mascara = condicao_receita & condicao_custos
print(df_unidades[mascara])
```

``` text
  unidade   regiao  receita  custos
0      U1      Sul      180     125
4      U5  Sudeste      195     138
```

U1 e U5 atendem aos dois critérios. U3 tem receita suficiente, mas custos de 152, superiores a 140; não deve entrar apenas por sua receita elevada. Os limites estão em milhares de reais.

## Solução do Exercício 04

A primeira consulta usa `|`, pois aceita qualquer uma das duas regiões. A segunda usa `~` para inverter a condição Sul. Os colchetes finais limitam a apresentação a unidade e região; não atribuímos valores através dessas seleções.

``` python
sul = df_unidades["regiao"] == "Sul"
sudeste = df_unidades["regiao"] == "Sudeste"
print(df_unidades[sul | sudeste][["unidade", "regiao"]])
print("Fora do Sul:")
print(df_unidades[~sul][["unidade", "regiao"]])
```

``` text
  unidade   regiao
0      U1      Sul
1      U2  Sudeste
2      U3      Sul
4      U5  Sudeste
Fora do Sul:
  unidade        regiao
1      U2       Sudeste
3      U4  Centro-Oeste
4      U5       Sudeste
5      U6         Norte
```

Sul ou Sudeste inclui U1, U2, U3 e U5. Fora do Sul inclui U2, U4, U5 e U6. As consultas são diferentes: uma enumera duas categorias aceitas, enquanto a outra exclui uma categoria.

## Solução do Exercício 05

`isin()` concentra os rótulos aceitos em uma lista. Após aplicar a máscara, `shape[0]` consulta o número de linhas: o índice 0 da tupla de dimensões corresponde à quantidade de observações.

``` python
mascara_regioes = df_unidades["regiao"].isin(["Sul", "Sudeste"])
resultado = df_unidades[mascara_regioes]
print(resultado[["unidade", "regiao"]])
print("Quantidade:", resultado.shape[0])
```

``` text
  unidade   regiao
0      U1      Sul
1      U2  Sudeste
2      U3      Sul
4      U5  Sudeste
Quantidade: 4
```

São quatro linhas, referentes a U1, U2, U3 e U5, como na primeira consulta do Exercício 04. A coincidência não depende só da contagem: os identificadores também confirmam a seleção pretendida.

<a id="sol-ch08-06"></a>

## Solução do Exercício 06

`between(145, 195)` usa limites inclusivos por padrão. Aplicamos a máscara em `.loc` e escolhemos as colunas que permitem verificar unidade e receita lado a lado.

``` python
mascara_intervalo = df_unidades["receita"].between(145, 195)
print(df_unidades.loc[mascara_intervalo, ["unidade", "receita"]])
```

``` text
  unidade  receita
0      U1      180
1      U2      145
3      U4      168
4      U5      195
```

U1, U2, U4 e U5 permanecem. U2 está no limite inferior, 145, e U5 no superior, 195. A presença das duas é coerente com o enunciado. U3, com 210, fica acima da faixa.

<a id="sol-ch08-07"></a>

## Solução do Exercício 07

Uma possibilidade legível é usar `isin()` para a lista de regiões e `between()` para a faixa de receita. A cópia mantém uma versão de trabalho da base. Combinamos as duas máscaras com `&`, pois a unidade precisa atender aos dois requisitos.

``` python
df_desafio = df_unidades.copy()
mascara_regiao = df_desafio["regiao"].isin(["Sul", "Sudeste"])
mascara_receita = df_desafio["receita"].between(160, 205)
resultado_desafio = df_desafio[mascara_regiao & mascara_receita]
print(resultado_desafio)
```

``` text
  unidade   regiao  receita  custos
0      U1      Sul      180     125
4      U5  Sudeste      195     138
```

U1 e U5 satisfazem a regra. U4 tem receita na faixa, mas pertence ao Centro-Oeste; U3 pertence ao Sul, mas tem receita acima do limite. Comparações explícitas equivalentes também são aceitáveis quando a justificativa e os limites estiverem corretos.

## Solução do Exercício 13

Esta é uma solução possível. Selecionamos as cinco colunas originais para explicitar o ponto de partida e fazemos uma cópia. Depois calculamos saldo e percentual executado, convertemos ano para texto e recodificamos prioridade. Como todos os orçamentos são positivos, gasto não superior ao orçamento corresponde a percentual executado de no máximo 100%.

``` python
df_pipeline = df_projetos[["projeto", "orcamento", "gasto", "prioridade", "ano"]].copy()
df_pipeline["saldo"] = df_pipeline["orcamento"] - df_pipeline["gasto"]
df_pipeline["executado_pct"] = df_pipeline["gasto"] / df_pipeline["orcamento"] * 100
df_pipeline["ano"] = df_pipeline["ano"].astype(str)
df_pipeline["prioridade"] = df_pipeline["prioridade"].replace({"A": "Alta", "B": "Média", "C": "Baixa"})
mascara = df_pipeline["executado_pct"] <= 100
relatorio = df_pipeline[mascara].sort_values("executado_pct", ascending=False)
print(relatorio)
print("Dimensões:", relatorio.shape)
print("Colunas:", list(relatorio.columns))
print("Ordem decrescente:", relatorio["executado_pct"].is_monotonic_decreasing)
```

``` text
  projeto  orcamento   gasto prioridade   ano  saldo  executado_pct
4      P5     135000  128000      Média  2025   7000      94.814815
2      P3     150000  142000       Alta  2025   8000      94.666667
3      P4     110000  101000      Baixa  2025   9000      91.818182
0      P1     120000  108000       Alta  2025  12000      90.000000
Dimensões: (4, 7)
Colunas: ['projeto', 'orcamento', 'gasto', 'prioridade', 'ano', 'saldo', 'executado_pct']
Ordem decrescente: True
```

O relatório contém P5, P3, P4 e P1, nessa ordem, e tem forma (4, 7). P2 fica fora porque gastou aproximadamente 102,11% do orçamento. Os percentuais restantes são aproximadamente 94,81%, 94,67%, 91,82% e 90%. `shape`, nomes de colunas, valores exibidos e a propriedade de ordem oferecem conferências específicas. O percentual mede uso do orçamento, não avanço físico, conclusão ou sucesso do projeto. A conversão de ano deve ser lida à luz do comportamento textual da versão de pandas utilizada.

## Solução do Exercício 19

Conferimos forma, nomes e sequência. `unique()` devolve valores distintos na ordem em que aparecem, e `list()` facilita sua leitura. Mantemos a inspeção dos turnos na base de trabalho e a complementamos com uma consulta direta ao relatório, para verificar o objeto efetivamente entregue. A propriedade de ordem admite empates. Por fim, retomamos o filtro de meta e custo do Exercício 15 e usamos `.iloc[0]` para acessar a primeira posição do relatório ordenado. Consulte também a documentação de valores únicos (The pandas development team s.d.).

``` python
print("Dimensões do relatório:", relatorio_vertice.shape)
print("Colunas:", list(relatorio_vertice.columns))
print("Turnos presentes:", list(vertice_trabalho["turno"].unique()))
print("Turnos no relatório:", list(relatorio_vertice["turno"].unique()))
print("Ordem decrescente:", relatorio_vertice["cumprimento_pct"].is_monotonic_decreasing)
print("Unidades que atendem meta e custo:", list(resultado_criterios["unidade"]))
print("Maior cumprimento observado:", relatorio_vertice.iloc[0]["unidade"])
```
