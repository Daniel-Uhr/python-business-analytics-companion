## Solução do Exercício 01

Antes de escolher um método, identificamos o objeto descrito por cada linha. A base traz vendas individuais. Agrupar por loja reunirá todas as vendas de cada estabelecimento, e a tabela resumida terá uma linha por loja. O código registra essa interpretação em duas mensagens; `print()` comunica a resposta, mas não realiza uma agregação.

``` python
print('Original: uma linha representa uma venda.')
print('Agregado por loja: uma linha representa uma loja.')
```

``` text
Original: uma linha representa uma venda.
Agregado por loja: uma linha representa uma loja.
```

Passar de venda para loja muda o nível da apresentação. A base original continua sendo uma base de sete vendas, mesmo que seu resumo tenha três linhas.

<a id="sol-ch10-02"></a>

## Solução do Exercício 02

“Quanto vendeu?” pede acumular receita. `groupby("loja")` reúne as linhas de cada loja, `["receita"]` seleciona a medida e `sum()` adiciona seus valores. Guardamos a Series em `receita_total` para reaproveitá-la na comparação do Exercício 06.

``` python
receita_total = df_lojas.groupby('loja')['receita'].sum()
print(receita_total)
```

``` text
loja
Alfa    1800
Beta    2000
Gama    1200
Name: receita, dtype: int64
```

Alfa acumula R\$ 1.800; Beta, R\$ 2.000; Gama, R\$ 1.200. A unidade é reais. Beta tem o maior total observado, o que ainda não informa quantas vendas ocorreram nem seu valor médio.

<a id="sol-ch10-03"></a>

## Solução do Exercício 03

Mantemos os mesmos grupos e a mesma coluna, mas trocamos a operação final por `mean()`. A mudança de método corresponde a uma mudança de pergunta: buscamos o valor médio de uma venda, não a receita acumulada. A Series será usada novamente no Exercício 06.

``` python
receita_media = df_lojas.groupby('loja')['receita'].mean()
print(receita_media)
```

``` text
loja
Alfa     600.0
Beta    1000.0
Gama     600.0
Name: receita, dtype: float64
```

Beta apresenta R\$ 1.000 por venda; Alfa e Gama, R\$ 600 por venda. O empate das médias de Alfa e Gama não implica empate de totais, pois as quantidades de vendas podem diferir.

<a id="sol-ch10-04"></a>

## Solução do Exercício 04

Cada linha é uma venda, portanto queremos o tamanho de cada grupo. `size()` conta suas linhas sem depender de uma coluna de receita estar preenchida. Diferentemente de `count()` sobre uma coluna, não conta apenas seus valores disponíveis. Guardamos a resposta para o Exercício 06.

``` python
numero_vendas = df_lojas.groupby('loja').size()
print(numero_vendas)
```

``` text
loja
Alfa    3
Beta    2
Gama    2
dtype: int64
```

Alfa tem três vendas; Beta e Gama, duas cada. As contagens somam as sete linhas da base. Isso descreve escala de transações, não valor monetário.

Depois de agrupar por `unidade` e selecionar `receita`, passamos a `agg()` uma lista de operações. Cada string designa um cálculo sobre o mesmo conjunto de receitas do grupo; a resposta tem uma linha por unidade operacional e quatro colunas.

``` python
medidas = (
    df_ordens.groupby('unidade')['receita'].agg(['sum', 'mean', 'min', 'max'])
```

## Solução do Exercício 09

Na agregação nomeada, cada argumento à esquerda cria um nome de saída e a tupla à direita associa coluna e operação. Receita total e média usam `receita`; número de ordens usa `count` em `ordem_id`. Esse identificador está completo nesta base, em que cada linha é uma ordem.

``` python
indicadores_receita = df_ordens.groupby('unidade').agg(
    receita_total=('receita', 'sum'),
    receita_media=('receita', 'mean'),
    numero_ordens=('ordem_id', 'count'),
)
print(indicadores_receita)
```

``` text
         receita_total  receita_media  numero_ordens
unidade
A                 3600         1200.0              3
B                 4800         1600.0              3
C                 2300         1150.0              2
```

Os totais e médias permanecem iguais aos do 08. As contagens são 3/3/2 ordens. Os nomes comunicam as medidas, mas a contagem não seria automaticamente o número de linhas se IDs estivessem ausentes; também não é uma contagem de IDs distintos.

## Solução do Exercício 11

Partimos da `tabela` do 10. Subtraímos custo total de receita total, mantendo o alinhamento por unidade operacional. Em seguida dividimos esse resultado pela receita total da mesma linha e multiplicamos por 100. Os denominadores são positivos nesta base. `round(2)` controla apenas a apresentação enviada ao `print()`.

``` python
tabela['resultado_total'] = tabela['receita_total'] - tabela['custo_total']

```

## Solução do Exercício 12

``` python
print('Receita validada:', tabela['receita_total'].sum() == df_ordens['receita'].sum())
print('Ordens validadas:', tabela['numero_ordens'].sum() == df_ordens.shape[0])
```

## Solução do Exercício 18

Voltamos a `df_delta`, pois o resumo somente por centro não mantém o detalhe do tipo. Passamos centro e tipo como duas chaves, selecionamos unidades e somamos. `reset_index()` transforma os rótulos de agrupamento em colunas, sem desfazer a agregação.
